## 要交付的行為

使用者能在比較表檢視各候選的差異與結果，排序後仍能開啟正確棋譜，將選中的實際設定另存並用於下次對戰。

## 驗收條件

- [ ] 表格包含參數差異、勝和敗、完整配對得分率、完整配對數、未完成數及對局耗時，九組以上也能正常瀏覽。
- [ ] 得分率只計入完整成對終局，勝 1／和 0.5；孤立完成局、截斷、停止及失敗不補成和棋，無完整配對顯示無資料而非 0%。
- [ ] 耗時標示清楚區分累積對局時間與實驗經過時間；並行工作時間不誤作牆鐘等待時間。
- [ ] 可排序數值欄位，無資料明確區分；排序不改變儲存識別或自動宣稱最強設定。
- [ ] 排序後開啟的棋譜與候選一致；另存使用實際完整候選快照，不重算百分比、不覆寫基準。
- [ ] 新設定可從現有真人對戰／比較選單載入，設定往返一致；舊比較紀錄仍能閱讀，不造出不存在的新統計。
- [ ] UI 到紀錄讀取、回放與另存的行為測試涵蓋完整／半組配對及排序後候選識別，避免測靜態文字。
