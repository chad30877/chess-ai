## 原文

## Problem Statement

目前評分器已有多個可調評分項，但分數拆解沒有出現在棋譜回放中，使用者難以理解各項如何影響局面分數。建立、調整多份評分設定檔也缺少順手的流程；真人對 AI 不能選擇設定檔或使用 Alpha-Beta。使用者希望以逐步、可檢視的方式調整既有設定，並以一致條件比較多份候選。

## Solution

在棋譜回放中顯示選定局面的靜態評分與已啟用評分項貢獻，並讓使用者以該棋譜實際使用的設定為起點調整既有欄位、即時查看局面分數變化、另存新設定檔。真人對 AI 加入 Alpha-Beta，讓對局可選擇已保存的評分設定檔。評分比較則擴充為一份基準對多份候選，以共同條件對局並並排呈現結果。

交付順序：
1. 棋譜回放的靜態評分拆解。
2. 回放內調整設定、即時重算與另存新檔。
3. 真人使用設定檔對 Alpha-Beta 對局。
4. 多候選設定對照同一基準。

## User Stories

1. As a 棋譜回放使用者, I want 在目前回放局面看到總分, so that 我能快速理解評分器對此局面的判斷。
2. As a 棋譜回放使用者, I want 知道總分是局面靜態評分, so that 我不會把它誤認為 Alpha-Beta 搜尋結果。
3. As a 棋譜回放使用者, I want 總分以兵為單位、從白方視角呈現, so that 正負值有一致含義。
4. As a 棋譜回放使用者, I want 以 0 為中心的雙向條形圖看到各已啟用評分項, so that 我能比較各項的正負方向和貢獻大小。
5. As a 棋譜回放使用者, I want 每個條形圖項目顯示精確分數, so that 我可以核對分項加總和總分。
6. As a 棋譜回放使用者, I want 選取棋譜步數後看到落子完成後的評分, so that 評分局面與目前棋盤一致。
7. As a 棋譜回放使用者, I want 在現有回放資訊面板看到評分, so that 我不必切換到另一個分析頁。
8. As a 調整評分設定的使用者, I want 從棋譜保存的實際設定建立草稿, so that 我能以重現該局 AI 行為的設定為起點。
9. As a 調整評分設定的使用者, I want 按類別收合現有可調項, so that 編輯器不會一次顯示過多欄位。
10. As a 調整評分設定的使用者, I want 預設聚焦已啟用的評分項, so that 我能先處理目前參與計分的設定。
11. As a 調整評分設定的使用者, I want 修改既有設定欄位後立即看到該局面的總分和分項更新, so that 我能理解設定變化對此局面的影響。
12. As a 調整評分設定的使用者, I want 把修改後設定另存為新設定檔, so that 原設定和既有對局紀錄仍可重現。
13. As a 調整評分設定的使用者, I want 保留原設定並能放棄未保存草稿, so that 試驗不會意外覆寫設定。
14. As 一位下棋的使用者, I want 在真人對局選擇一份已保存的評分設定檔, so that 我能實際體驗不同評分設定。
15. As 一位下棋的使用者, I want 與使用該設定檔的 Alpha-Beta AI 對局, so that AI 能使用多步搜尋而非只看單步。
16. As 一位下棋的使用者, I want 固定深度 Alpha-Beta 預設使用深度 2, so that 初次對局有明確且可重現的搜尋設定。
17. As 一位下棋的使用者, I want 先只調整搜尋深度, so that 對局設定不會被其他搜尋選項淹沒。
18. As 一位下棋的使用者, I want 真人對局初始選用 stable 設定檔, so that 不必先建立設定就能開始對局。
19. As 一位查看真人棋譜的使用者, I want 棋譜保存實際使用的評分與搜尋設定, so that 之後仍能重現和解釋這盤棋。
20. As 一位比較評分設定的使用者, I want 一次選一份基準與多份候選, so that 我能在同一批實驗中檢查多種設定。
21. As 一位比較評分設定的使用者, I want 每份候選使用相同局面集、搜尋設定與預算對照基準, so that 結果能公平比較。
22. As 一位比較評分設定的使用者, I want 每個起始局面交換黑白, so that 先後手影響能被控制。
23. As 一位比較評分設定的使用者, I want 並排查看各候選對基準的結果, so that 我能逐一判讀候選而不把小樣本當成確定排名。
24. As 一位調整評分設定的使用者, I want 用回放分數理解局面、用成對對局評估棋力, so that 單一局面的改善不會被誤認為整體棋力提升。
25. As 一位調整評分設定的使用者, I want 以未參與調整的局面驗證候選設定, so that 我能檢查設定是否只適合已反覆查看的棋局。

## Implementation Decisions

- 評分項集合維持現況；本規格不新增評分項。
- 回放顯示局面靜態評分，不把 Alpha-Beta 搜尋分數混入分項圖。總分與分項均以兵為單位、白方視角表示。
- 條形圖以 0 為中心；正值向右代表有利白方，負值向左代表有利黑方。只顯示已啟用評分項，並顯示精確貢獻。
- 評分使用棋譜目前選定步完成後的棋盤，放在現有回放資訊面板。
- 調參草稿以該棋譜保存的實際評分設定為起點。所有既有可調欄位按類別收合，預設展開已啟用項；調整時重新計算目前局面的靜態評分。
- 設定以另存新檔保存，不覆寫原設定。只有已保存的設定檔能被真人對局選用。
- 真人對 AI 支援 Alpha-Beta 固定深度搜尋，預設深度 2，初版只向使用者提供深度設定；其他搜尋選項沿用現有預設。真人對局設定頁可選評分設定檔，預設 stable.json。
- 真人棋譜保存實際評分設定及 Alpha-Beta 搜尋設定。
- 多候選比較使用共同基準、局面集、搜尋設定和預算；每個局面交換黑白，結果逐候選呈現，不自動產生最佳設定排名。
- 調參流程每輪只改少量相關權重，記錄預期影響；以未參與調整的新局面驗證候選。回放分數是理解工具，不是棋力證據。

## Testing Decisions

- 測試使用者可觀察的完整行為，不鎖定繪圖私有函式、欄位存在與否或其他實作細節。
- 回放驗收涵蓋目前選定局面、總分、分項方向與精確值；總分應與已啟用分項貢獻一致。
- 調參驗收涵蓋複製棋譜設定、修改後即時更新、另存後重新載入，以及原設定未被覆寫。
- 真人對局驗收涵蓋所選評分設定與深度確實用於 AI 選步，並出現在已保存棋譜設定中。
- 多候選比較驗收涵蓋共同實驗條件、交換黑白、候選各自的結果及完整／未完成配對處理。
- 先前的回放 UI、真人 LiveSession 和評分比較流程已有外部行為測試，可沿用其測試邊界與資料模式。

## Out of Scope

- 新增評分項、機器學習或自動調整評分權重。
- 在進行中的真人棋局即時顯示分數圖。
- Alpha-Beta 固定時間搜尋、棋鐘或悔棋。
- 依有限樣本自動宣布最佳設定，或宣稱已證明棋力提升。

## Further Notes

- 設定比較應固定搜尋條件並交換黑白；候選應以未用來調整的局面驗證。
- 版本化完整設定快照是回放調整、真人對局與實驗結果可重現的共同基礎。
