## What to build

在棋譜回放中查看目前局面的靜態評分，能直接理解總分由哪些已啟用評分項組成。

## Acceptance criteria

- [ ] 選取棋譜步數時，評分對應落子後的目前棋盤；初始局面也能正確顯示。
- [ ] 現有回放資訊面板顯示白方視角、以兵為單位的靜態總分。
- [ ] 以 0 為中心的雙向條形圖只顯示已啟用評分項；正值向右、負值向左，並顯示精確貢獻值。
- [ ] 總分和圖表清楚表示是局面靜態評分，不混淆 Alpha-Beta 搜尋分數。
- [ ] 已啟用項目貢獻加總與顯示總分相符。
