## 要完成的行為

評分比較可透過 UI、CLI 與服務設定搜尋 worker 及置換表容量；基準設定和每份候選設定使用相同條件，交換黑白的結果仍逐場保存。

## 驗收條件

- [x] UI、CLI、比較參數及實際玩家共同傳遞搜尋 worker 與有界置換表設定，並驗證基準設定與候選設定使用一致條件。
- [x] 同時對局數與搜尋 worker 數保持獨立，不新增按乘積限制 CPU 的規則。
- [x] 交換黑白配對、共同種子、多候選、未完成配對及不自動排名語意保留；比較仍不提供暫停。
- [x] 實際設定快照、批次資料與比較摘要反映新條件；必要時版本化，既有比較紀錄仍可讀取。
- [x] 每場完成即發布，不等待整組配對完成；合作式停止與 worker 錯誤會清理內外程序，保留已保存結果與未完成配對。
- [x] 沿用完整比較流程測試 UI／CLI 設定生效、配對發布、舊資料相容與有界 Windows spawn；避免只驗證參數轉送存在。
- [x] 人工以一份基準及多份候選跑短局，檢查各方設定快照、逐場保存與停止後不完整配對。
