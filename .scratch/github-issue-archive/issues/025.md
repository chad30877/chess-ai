## 要交付的行為

使用者從實驗紀錄選擇續跑，關閉程式或意外中斷前已完成的棋局保留，只執行剩餘工作，最終配對結果不重複也不混入新設定。

## 驗收條件

- [ ] 停止／關閉後重新啟動，可從保存實驗重新建立工作，使用不可變的基準、候選、開局、種子與搜尋條件。
- [ ] 已提交完成的棋局不重跑；半組配對保留完成的顏色，只補另一局。未完成工作可從該局起點重跑，中斷嘗試不重複計入有效結果。
- [ ] 正常因手數上限截斷的工作保留未完成結果，不在每次續跑無限重試，不改列和棋。
- [ ] 處理棋局已保存但進度未更新的故障點，重開可按穩定工作識別恢復一致狀態，不漏局、不重複計數、不覆寫完成紀錄。
- [ ] 原設定檔變更不影響實驗快照；程式／特徵或保存契約不相容時拒絕混接並明示原因。缺必要快照的舊紀錄仍可讀，但不猜測條件續跑。
- [ ] 同一實驗不得同時被兩個執行者續跑；失效的執行中狀態可恢復，已完成實驗不再派工。
- [ ] 續跑前後完整配對統計與等條件不中斷執行一致，已保存紀錄隨時可回放；停止、故障與重開均正確清理兩層工作程序。
- [ ] 以 UI／比較入口整合測試覆蓋正常停止、半組配對及保存邊界故障，至少一項跨新程序重開測試；人工驗收能停止後關閉再繼續。
