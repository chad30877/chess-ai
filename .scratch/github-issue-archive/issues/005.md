## What to build

在同一批評分比較中選擇一份基準與多份候選，並以一致的對局條件分別比較及呈現結果。

## Acceptance criteria

- [ ] 可選一份基準與多份不同候選評分設定檔。
- [ ] 所有候選共用相同的起始局面集、搜尋設定、預算與配對條件。
- [ ] 每份候選在每個起始局面各執一次白、一次黑，配對結果與未完成配對分開計算。
- [ ] 結果逐候選呈現基準對照的勝、和、敗與配對得分率。
- [ ] 候選結果並排可讀，不依有限樣本自動選出或排名最佳設定。
- [ ] 批次保存可追溯每份候選與基準的完整設定快照和共同搜尋條件。
