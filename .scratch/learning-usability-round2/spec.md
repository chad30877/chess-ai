# 學習介面第二輪調整

狀態：設計訪談中，尚未核准完整規格或開始實作。

## 已確認方向

- 資料來源保留本機檔案／線上下載切換，記住上次選擇。本機顯示完整路徑與選檔按鈕，線上顯示來源網址。
- 種子保留手動輸入並提供隨機按鈕；使用者接受以毫秒時間產生，實際產生值須顯示並保存。
- 重複教師標記判定包含相同資料、種子及教師條件；完成結果選用、中斷結果續跑、執行中結果顯示進度，明確要求重新評分才另建。
- 教師先導併入教師評分頁，不以估時獨占頁面。
- 學習可選歷次完成的教師評分；其他教師作業執行中不應阻擋使用完成資料的學習與既有候選比較。
- 候選介面不分單群組與多群組。群組固定五欄 `PSMKC`：P=棋子位置、S=兵形、M=活動力、K=王安全、C=協調；未使用群組以 `-` 佔位，例如 `P--K-`。
- 來源方式以 `D=直接組合、J=聯合學習、U=自訂` 表示，例如 `J:P--K-`；頁面提供 D、J、U、P、S、M、K、C 的完整圖例。
- 候選包含所有有效設定檔：預設、自訂及已產出的學習設定，不要求學習報告。沒有指標顯示未評估；先載入設定摘要，詳細來源驗證延至需要時。
- 本輪增加候選清單篩選及依棋力／驗證誤差排序，不擴充快速對戰篩選。排序指標、可比條件與缺值處理待確認。
- 刪除舊棋子位置成果頁，不另保留歷史頁入口。此決策不等同授權刪除已保存資料。
- 修正錯誤訊息與資料摘要重疊。
- 如需真實教師評分等待，先提供可操作介面，再停止 Agent 工作等待使用者繼續；目前未啟動長作業。

## 待釐清

- 棋力排序使用的指標與比較條件；驗證誤差定義及不同驗證來源的處理。
- 指標缺漏、同一設定具有多筆評估時的排序方式。

## 已查明的現況

- 資料來源本機模式只有手動輸入路徑，無選檔按鈕。
- 錯誤訊息與已載入資料摘要使用相同繪製座標。
- 作業啟動受全域執行狀態阻擋，學習來源另綁定目前教師標記。
- 候選清單會讀取研究輸入、驗證來源及讀取比較報告；不掃描全部自訂設定檔，且研究候選需要完成報告與有效教師誤差。尚未量測效能。
- 教師先導另包含引擎選擇、程序數與搜尋預算設定，併頁時仍需提供這些控制。
- 教師標記不可用尚未實際重現，根因待查。
