關閉、盤點與手動恢復已實作並完成驗收及複審；證據與限制如下。

## 要交付的行為

有任務時關閉程式可選繼續執行或停止保存後離開；重開能找到未完成工作，由使用者決定續跑。失敗與停止都依各工作實際恢復能力呈現操作。

## 範圍與界線

沿用現有逐局面、逐候選及逐對局的保存粒度；不建立關閉後持續運算的背景服務，不擴充教師先導續跑。比較清單專用入口由 UI09 接入此恢復行為。

參考位置：`apps/chess_application.py`、`ui/learning_view.py`、教師與學習停止／續跑入口、`engine/sessions/experiment_resume.py`。檔案位置僅供探索定位，不限制合理實作方式。

## 功能驗收與驗證方式

- [x] 取消關閉後原任務繼續。驗證：教師、學習與比較各以小任務觸發關閉並取消，核對任務未被替換或意外停止。
- [x] 確認離開後完成停止與保存才退出。驗證：在保存邊界延遲回應，確認介面呈現處理狀態且不提早退出。
- [x] 關閉完成後沒有遺留教師、求解或比較子程序。驗證：沿用既有外部程序與真實 spawn 清理驗證。
- [x] 重開會列出未完成工作而不自動啟動。驗證：保存未完成的標記、訓練及比較資料後重開，核對沒有開始新運算。
- [x] 教師標記續跑只補未完成或需重試的局面。驗證：比對停止前後已提交記錄並經公開入口續跑。
- [x] 學習續跑保留已完成候選並重算未完成求解。驗證：在強度候選邊界停止後重開，核對已完成成果未被重做。
- [x] 比較續跑保留已完成對局並從缺少對局的開局起點重算。驗證：半組交換黑白對局停止重開，核對棋譜與缺少顏色。
- [x] 未完成教師先導明示需重新量測且沒有續跑按鈕。驗證：載入停止的先導並操作可用恢復入口。
- [x] 失敗後恢復操作符合任務能力且保留已保存進度。驗證：可控制失敗後重開，分別執行重新量測或續跑並核對來源。

## 人工重現方式（尚未執行）

在小任務執行中關閉，先取消，再確認停止保存；重開後手動續跑，另查看停止的教師先導只有重新量測操作。

## 驗收證據與限制

- 應用程式事件驗證教師先導、教師標記、單群組學習及比較的取消關閉、停止保存與手動恢復；取消後先導、單群組及短比較分別完成。控制背景執行與保存邊界，核對確認後仍在處理且不提早退出。
- 真實教師程序、spawn 求解程序與比較工作程序各在執行中由 UI 關閉並核對退出後無遺留；既有教師、單群組及比較停止／續跑測試比對提交成果與配對紀錄。
- 重開時背景盤點已保存任務，先驗證來源與成果，再由使用者選擇開啟或續跑；先導只提供重新量測。失敗標記續跑與失敗先導重新量測均以小資料驗證。
- 控制讀取完成次序，核對舊資料不覆蓋恢復來源；混合缺少狀態、缺欄位及損壞組合的情境確認可見不可用項且不阻擋正常任務。
