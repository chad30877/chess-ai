## 要交付的行為

從候選清單選擇快速篩選或完整比較，開始前看見候選、基準與總局數；原始設定與學習設定對照保留獨立入口。不同來源候選依共同條件建立比較，執行接入共用任務控制。

## 範圍與界線

沿用快速篩選、完整比較、共同開局與凍結規則；完整比較仍須符合既有篩選及候選數限制，不因直接入口跳過研究前置。本票交付建立與啟動，歷史查找與結果摘要由 UI09 負責。

參考位置：`ui/candidate_inventory_view.py`、`ui/screening_view.py`、`ui/learned_comparison_view.py`、`engine/learning/screening.py`、`engine/learning/final_comparison.py`、`engine/learning/comparison.py`。檔案位置僅供探索定位，不限制合理實作方式。

## 功能驗收與驗證方式

- [x] 快速篩選預覽與實際計畫使用目前勾選的有效候選。驗證：跨來源選取後建立計畫，核對保存設定與來源。
- [x] 完整比較只能使用符合既有篩選條件的候選。驗證：混合未篩選、通過及未通過者，核對可選性與開始阻擋。
- [x] 缺少完整比較前置時可直接前往快速篩選。驗證：從受阻完整比較操作引導入口並保留可用選擇。
- [x] 開始前顯示實際基準及總局數。驗證：三候選快速篩選為 48 局，通過篩選後雙基準完整比較為 384 局，對照實際計畫。
- [x] 原始設定與學習設定對照有可直接使用的獨立入口。驗證：舊單組與組合來源開啟對照，核對原始／學習角色。
- [x] 對照用途的工作量依實際角色與基準計算。驗證：切換角色及 stable 參照，核對預覽與計畫，不套用固定 128 局總數。
- [x] 不同來源比較仍使用共同對戰條件。驗證：核對凍結搜尋條件、共同開局、基準及交換黑白計畫。
- [x] 開始前來源失效不會建立錯誤比較。驗證：預覽後令來源不可用再開始，核對錯誤提示及任務未啟動。
- [x] 比較任務遵守跨頁繼續、互斥與停止保存行為。驗證：執行短比較後切頁、嘗試另一工作並停止，核對已保存棋譜。

## 驗收證據與限制

已實作多候選用途預覽、既有比較計畫凍結、來源重驗及單一背景工作。三候選快速篩選 48 局與完整比較 384 局的實際凍結計畫測試使用可控制篩選結果邊界，未執行正式對局；小型合法短局事件測試涵蓋跨頁、互斥、停止及棋譜保存。來源失效測試確認未建立比較任務或計畫；原始／學習對照角色及基準數量測試通過。跨票 UI08、群組草稿及關閉流程 29 項通過；群組及組合 UI 回歸 8 項通過。獨立審查確認損壞計畫隔離、舊雙角色計畫重用條件與既有入口來源重驗。舊單組及組合入口以真實 UI 事件檢驗來源失效與角色；人工重現步驟尚未執行。

整合分支以專案虛擬環境複跑比較計畫與 UI、群組草稿、組合、關閉恢復及既有對照，共 35 項通過。獨立審查確認損壞資料、角色及直接對照來源修復；正式長對局未執行。
