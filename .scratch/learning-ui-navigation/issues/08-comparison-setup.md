# UI08：依比較用途選候選並預覽實際工作量

狀態：待開始。
阻擋來源：[UI04](04-stop-and-resume.md)、[UI07](07-all-candidates.md)。
對應決策：Q4、Q8、Q9、Q12、Q13。
規格：[學習實驗導覽與操作改善](../spec.md)。
索引：[本批工作票](../README.md)。

本輪僅建立工作票；未開始實作，以下功能與結案項目皆尚未驗收。依賴票未完成必要驗收前，不宣稱本票已解除阻擋。

## 要交付的行為

從候選清單選擇快速篩選或完整比較，開始前看見候選、基準與總局數；原始設定與學習設定對照保留獨立入口。不同來源候選依共同條件建立比較，執行接入共用任務控制。

## 範圍與界線

沿用快速篩選、完整比較、共同開局與凍結規則；完整比較仍須符合既有篩選及候選數限制，不因直接入口跳過研究前置。本票交付建立與啟動，歷史查找與結果摘要由 UI09 負責。

參考位置：`ui/candidate_inventory_view.py`、`ui/screening_view.py`、`ui/learned_comparison_view.py`、`engine/learning/screening.py`、`engine/learning/final_comparison.py`、`engine/learning/comparison.py`。檔案位置僅供探索定位，不限制合理實作方式。

## 功能驗收與驗證方式

- [ ] 快速篩選預覽與實際計畫使用目前勾選的有效候選。驗證：跨來源選取後建立計畫，核對保存設定與來源。
- [ ] 完整比較只能使用符合既有篩選條件的候選。驗證：混合未篩選、通過及未通過者，核對可選性與開始阻擋。
- [ ] 缺少完整比較前置時可直接前往快速篩選。驗證：從受阻完整比較操作引導入口並保留可用選擇。
- [ ] 開始前顯示實際基準及總局數。驗證：三候選快速篩選為 48 局，通過篩選後雙基準完整比較為 384 局，對照實際計畫。
- [ ] 原始設定與學習設定對照有可直接使用的獨立入口。驗證：舊單組與組合來源開啟對照，核對原始／學習角色。
- [ ] 對照用途的工作量依實際角色與基準計算。驗證：切換角色及 stable 參照，核對預覽與計畫，不套用固定 128 局總數。
- [ ] 不同來源比較仍使用共同對戰條件。驗證：核對凍結搜尋條件、共同開局、基準及交換黑白計畫。
- [ ] 開始前來源失效不會建立錯誤比較。驗證：預覽後令來源不可用再開始，核對錯誤提示及任務未啟動。
- [ ] 比較任務遵守跨頁繼續、互斥與停止保存行為。驗證：執行短比較後切頁、嘗試另一工作並停止，核對已保存棋譜。

## 驗證安排

以實際比較計畫驗證正式局數；執行驗證只跑小型合法開局或沿用既有短對局，不能為驗收預覽而跑完 384 局正式研究。
共通測試與結案規則見[索引](../README.md#驗收與結案規則)及[專案規範](../../../docs/agents/issue-tracker.md)。
