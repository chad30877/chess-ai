## 要交付的行為

開啟需要掃描或驗證保存資料的頁面時，先看到頁面與載入狀態，仍可返回；讀取完成後只更新目前仍有效的選擇。建立供後續成果及候選頁沿用的載入行為，並接入現有慢載入頁面。

## 範圍與界線

本票處理讀取期間與讀取失敗；已開始的教師、學習或對戰失敗由 UI03、UI04 處理。不得只信任進度摘要而略過既有資料驗證，也不以永久快取掩蓋錯誤。

參考位置：`ui/learning_view.py`、`ui/teacher_view.py`、`ui/label_view.py` 與既有保存資料載入入口。檔案位置僅供探索定位，不限制合理實作方式。

## 功能驗收與驗證方式

- [ ] 完整資料讀取結束前已呈現目的頁與載入狀態。驗證：在外部讀取邊界控制延遲，從應用程式事件確認仍可繪製及處理輸入。
- [x] 載入期間返回可立即生效。驗證：在讀取未完成時操作返回，確認目的頁與事件迴圈可繼續使用。
- [x] 過期讀取結果不覆蓋後來選取的來源或頁面。驗證：依序選 A、B，讓 A 最後完成，核對目前選擇與畫面仍為 B。
- [x] 資料未通過驗證前，依賴該結果的執行操作不可啟動。驗證：延遲及身分驗證失敗資料下嘗試開始，確認沒有建立運算任務。
- [x] 資料缺失或損壞會指出不可用的來源，不默默換成其他保存資料。驗證：準備一份正常與一份失效資料並選取後者，確認目前來源沒有被替換。
- [x] 讀取失敗後能重新讀取或改選其他成果。驗證：修復測試檔後重試，以及改選正常來源，確認頁面恢復可用。
- [x] 既有 5,809 筆標記的進頁等待有實測記錄。驗證：唯讀量測點擊至首次載入畫面及完整驗證時間，記錄快取條件；不設機器相關的硬性秒數門檻。
