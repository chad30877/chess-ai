## 功能驗收與驗證方式

- [ ] 完整資料讀取結束前已呈現目的頁與載入狀態。驗證：在外部讀取邊界控制延遲，從應用程式事件確認仍可繪製及處理輸入。
- [ ] 載入期間返回可立即生效。驗證：在讀取未完成時操作返回，確認目的頁與事件迴圈可繼續使用。
- [ ] 過期讀取結果不覆蓋後來選取的來源或頁面。驗證：依序選 A、B，讓 A 最後完成，核對目前選擇與畫面仍為 B。
- [ ] 資料未通過驗證前，依賴該結果的執行操作不可啟動。驗證：延遲及身分驗證失敗資料下嘗試開始，確認沒有建立運算任務。
- [ ] 資料缺失或損壞會指出不可用的來源，不默默換成其他保存資料。驗證：準備一份正常與一份失效資料並選取後者，確認目前來源沒有被替換。
- [ ] 讀取失敗後能重新讀取或改選其他成果。驗證：修復測試檔後重試，以及改選正常來源，確認頁面恢復可用。
- [ ] 既有 5,809 筆標記的進頁等待有實測記錄。驗證：唯讀量測點擊至首次載入畫面及完整驗證時間，記錄快取條件；不設機器相關的硬性秒數門檻。
