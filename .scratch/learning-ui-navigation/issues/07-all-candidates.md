## 要交付的行為

比較候選預設可找到所有既有學習來源的有效候選，包含舊獨立棋子位置、單群組、直接組合及聯合訓練；按來源及群組查找，不再只取一次五組訓練的前十名。

## 範圍與界線

查找與勾選不啟動對局。全來源查找不放寬組合來源相容性；不同訓練資料的教師誤差不能混排。比較執行與紀錄分別由 UI08、UI09 負責。

參考位置：`engine/learning/candidate_inventory.py`、`engine/learning/training.py`、`engine/learning/group_training.py`、`engine/learning/combination_training.py`、`ui/candidate_inventory_view.py`。檔案位置僅供探索定位，不限制合理實作方式。

## 功能驗收與驗證方式

- [ ] 候選清單涵蓋多個資料集及訓練來源。驗證：混合來源的保存結果經 UI 查找並核對候選身分。
- [ ] 舊獨立棋子位置完整成果可作為有效候選。驗證：以唯讀格式轉接載入並比對凍結設定、報告及來源身分。
- [ ] 舊資料在候選查找後保持原內容。驗證：查找、選取及重開前後比對原快照與報告。
- [ ] 超過十個有效候選仍可全部找到。驗證：至少十一份有效不同設定，操作清單至最後一筆並選取。
- [ ] 來源與群組篩選能正確限制候選範圍。驗證：不同來源及群組組合資料，逐次篩選並核對結果。
- [ ] 不同訓練資料的教師誤差分開呈現。驗證：兩來源數值刻意交錯，確認未形成跨來源誤差優劣排名。
- [ ] 同值設定的來源與誤差脈絡不會因合併顯示而遺失。驗證：兩個來源保存相同設定內容，檢視其來源與報告。
- [ ] 未完成報告或驗證失敗成果不可被選為可執行比較的候選。驗證：未完成、身分不相容與損壞資料的選取流程。
- [ ] 單一無效成果不讓其他有效候選無法查找。驗證：正常與失效資料混合清單，改選有效候選。
- [ ] 只開啟、篩選或勾選候選不會啟動對局。驗證：UI 事件後核對沒有新比較任務與棋譜輸出。

## 驗證安排

沿用候選盤點與公開候選載入契約，以新舊格式混合保存資料驗證。大量資料查找須接入 UI01 的可返回載入行為，不增加正式訓練或對局。
共通測試與結案規則見[索引](../README.md#驗收與結案規則)及[專案規範](../../../docs/agents/issue-tracker.md)。
