狀態：已完成。
阻擋來源：[UI08](08-comparison-setup.md)。

規格：[學習實驗導覽與操作改善](../spec.md)。

依賴票 UI08 已完成；本票必要驗收及獨立審查已完成。

## 要交付的行為

比較候選頁能直接切到既有比較紀錄，查看快速篩選、完整比較及原始／學習對照的進度、結果與回放。未完成紀錄可手動續跑，已保存的比較條件不受後來來源選擇影響。

## 範圍與界線

沿用現有設定棋力分數與有效對局判定，不從教師誤差推算棋力。此票接入 UI02 的名稱與選擇、UI04 的恢復及 UI08 的比較身分，不另建一套任務控制。

參考位置：`ui/learned_comparison_view.py`、`ui/screening_view.py`、`ui/records_view.py`、`engine/learning/rating.py`、`engine/sessions/experiment_resume.py` 及比較保存索引。檔案位置僅供探索定位，不限制合理實作方式。

## 功能驗收與驗證方式

- [x] 從比較候選頁可直接查找三種用途的既有比較紀錄。驗證：保存快速篩選、完整比較及原始／學習對照後由清單逐一開啟。
- [x] 比較紀錄顯示可讀名稱、來源、用途及完成狀態。驗證：不同狀態與長名稱紀錄的實際清單及畫面檢查。
- [x] 開啟紀錄使用原保存的候選與基準條件。驗證：改變目前清單選擇後開啟舊紀錄，核對凍結內容。
- [x] 續跑前可辨識已完成及剩餘工作量。驗證：半組配對紀錄重開，核對保存棋譜與顯示數量。
- [x] 從紀錄手動續跑只補缺少的對局。驗證：真實短比較停止後由新入口續跑，核對已完成棋譜未被覆寫。
- [x] 結果摘要呈現保存對局支持的勝和敗與對局數。驗證：完整與不完整配對混合紀錄，對照既有計算入口。
- [x] 設定棋力分數維持正式、暫估或尚未評分的實際狀態。驗證：對 stable 的足量／不足／缺少有效對局報告，對照評分來源及條件。
- [x] 未進行對戰的學習成果仍顯示尚未比較。驗證：只提供教師誤差報告，確認不生成棋力分數。
- [x] 比較結果可查看詳細條件與回放已保存棋局。驗證：從結果開啟明細、回放並返回原紀錄。
- [x] 損壞或缺失的紀錄不被默默換成其他結果。驗證：失效與正常紀錄混合，核對提示及改選恢復。

## 驗證安排

重用比較保存、續跑、回放與設定棋力分數測試；用實際棋譜及報告判斷狀態，不以固定文案或假排名取代結果驗證。
共通測試與結案規則見[索引](../README.md#驗收與結案規則)及[專案規範](../../../docs/agents/issue-tracker.md)。

## 人工重現方式（尚未執行）

在比較候選頁切到紀錄，開啟一份停止的比較並續跑；完成後查看勝和敗、棋力分數狀態及一盤回放，再返回原紀錄。

## 驗收證據與限制

三用途保存計畫的 UI 事件可逐一開啟原凍結來源；多候選整組可手動續跑，來源覆蓋不符會拒絕。真實短局停止後從紀錄續跑，已保存棋譜未覆寫，並核對結果及回放返回；另以半組配對確認已保存 1／2、剩餘 1 局及未評分。名稱與選擇重開保存，失效紀錄可提示並改選；延遲重驗時可切頁及停止。教師誤差但未對戰的候選顯示尚未比較。既有評分測試以棋譜驗證正式、暫估、未評分及無效局；比較與評分核心 23 項、跨票 UI／關閉流程 31 項、比較紀錄與既有對照 UI 11 項通過。已檢視實際紀錄清單畫面；獨立審查及複審完成。人工重現步驟尚未執行；未執行正式長研究。
