# 01：盤點組合並展示十個候選

## 上層規格

[組合研究與設定棋力分數](../spec.md)。

狀態：已完成。

## 要交付的行為

研究者可從已保存的同源單群組及多群組結果查看探索狀態，依驗證教師誤差列出最多十個不同設定，檢視來源及資料曝光後再決定如何處理；列出候選不啟動對局。

## 驗收條件

- [x] 透過公開研究入口盤點五個單群組及 26 種多群組，分別呈現直接組合、聯合訓練、缺漏與失敗，並可沿用條件相符的既有結果；以保存及重開驗證。
- [x] 從條件相符的 57 個非空候選中按驗證組逐盤平均教師絕對誤差列出最多十個不同設定，保留群組、產生方式、誤差及有效樣本量；以小型可控結果驗證排序與同內容去重。
- [x] 候選清單可查看資料、校準及測試曝光來源，未完成或不相容的結果不偽裝成完整排名；以不相容及缺漏情境驗證。
- [x] 十個候選呈現後不自動開始短對局，活動力＋王安全的四設定增量與兩種組合結果仍可查；以應用程式事件驗證。

## 阻擋

無，可立即開始。依賴既有已保存結果時不要求重新執行長研究。

## 實作與驗證紀錄

- 已新增已保存結果盤點與候選清單入口，依驗證誤差排序、設定內容去重，標示部分排名與來源；盤點不啟動對局。
- `tests.test_candidate_inventory` 以真實保存與重開流程涵蓋部分群組、直接與聯合結果、去重及應用程式事件；`tests.ui.test_combination_training` 通過既有組合操作回歸。
- `FullInventoryTest` 使用五組實際訓練結果及 26 組可控保存紀錄，核對 57 個狀態、排序前十、重複內容去重與重開；另驗證缺漏、失敗、損壞及來源不相容不構成完整排名。
- 以應用程式滑鼠事件開啟十個候選，確認沒有建立比較；組合介面回歸測試以滑鼠事件切回固定四設定，再查看直接與聯合結果。
- 限制：完整覆蓋測試的多群組報告為可控測試紀錄，並未執行正式長研究；人工操作未列為已執行驗收。
