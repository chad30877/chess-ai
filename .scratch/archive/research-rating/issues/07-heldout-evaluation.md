# 07：以未曝光資料評估凍結候選

## 上層規格

[組合研究與設定棋力分數](../spec.md)。

狀態：已完成。

## 要交付的行為

研究者在選定並凍結候選後，能使用未曝光的資料與教師標記評估教師誤差，並辨識資料來源及不足，不以最終測試結果重新挑選。

## 驗收條件

- [x] 候選與評估用途先凍結，未曝光資料及教師來源可追溯並與既有已曝光測試區分；以新舊資料身份驗證。
- [x] 以凍結設定評估教師誤差，報告包含有效盤數、局面數及階段分布；以小型可控資料及手算驗證。
- [x] 測試結果不自動重新訓練、挑選或改寫候選；以重開及資料變更情境驗證。
- [x] 資料不足、來源不相容或測試已曝光時顯示限制，不冒稱獨立驗證；以缺漏及錯誤來源驗證。

## 阻擋

- [06：對選定候選完成雙基準比較](06-final-comparison.md)；由該流程凍結要評估的候選，不要求使用者在軟體驗收時跑滿正式對局。

## 驗證證據與限制

- 自動測試以真實資料與教師標記流程建立新舊資料，核對資料身份、教師預算不相容、已曝光來源、少量資料、缺漏及不健康校準，並以應用程式滑鼠事件凍結、評估及重開。實際報告以純子力設定、棋子數與教師分數獨立核對逐盤平均誤差及有效樣本數；另有 `tests.test_weight_training.TrainingNumericTest` 手算契約。
- 評估不改寫候選或重新訓練，重開顯示已保存報告；僅能核對本機可讀研究來源，無法證明其他環境未曝光。未執行正式長研究。
- 新資料重開及修改原始資料後保存報告不變已測試；整合審查由整合流程執行。
