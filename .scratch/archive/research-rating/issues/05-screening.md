# 05：選定候選並執行短對局篩選

## 上層規格

[組合研究與設定棋力分數](../spec.md)。

狀態：已完成。

## 要交付的行為

研究者看過十個候選後，能明確選擇候選進行對 stable 的短對局，查看暫估與淘汰結果，再決定最多五個候選；對局不中途自動展開下一階段。

## 驗收條件

- [x] 由候選清單明確選擇後才建立短對局，各設定對 stable 以相同八條合法開局線交換黑白各一局；以實際流程及凍結設定驗證。
- [x] 短對局線與完整比較的 32 條線沒有相同的起始局面及完整走法序列；以來源與序列比對驗證。
- [x] 完成 16 局後依勝加半和計分，得分不超過 2 分標示淘汰，並顯示真實勝和敗及暫估分數；以手算及邊界資料驗證。
- [x] 未完成配對或停止、失敗、截斷不觸發淘汰、不更新正式分數；以停止重開及缺局情境驗證。
- [x] 短對局結果可供使用者查看並手動決定最多五個候選，少於五個或沒有候選時不自動補足及開跑；以應用程式事件驗證。

## 驗證證據與限制

- 整合審查補驗：淘汰候選無法選定，無通過者不能凍結完整比較。

- `tests.test_screening` 驗證實際凍結條件、八條開局與正式線不重複、手算淘汰邊界、真實保存的停止與續跑、受控失敗及截斷，並確認短對局不列入正式分數。
- 應用程式滑鼠事件測試驗證候選選擇後建立預覽而不自動開跑、重開沿用、零個或一個選擇及上限五個。完成狀態使用受控報告，正式長對局未執行。
