# 04：在設定選擇處查看棋力分數

## 上層規格

[組合研究與設定棋力分數](../spec.md)。

狀態：已完成；整合審查已完成。

## 要交付的行為

使用者選擇評分設定檔時，可查看符合目前對局條件的棋力分數及實際對局依據，未評分的設定清楚標示狀態。

## 驗收條件

- [x] 透過實際設定選擇流程可查看正式分數、對局條件及未評分狀態；以應用程式事件驗證。
- [x] 可查看分數對應的真實勝和敗、局數及來源；以已保存比較結果驗證。
- [x] 相同評分內容的不同檔名共用分數，變更評分內容後不沿用舊分數；以另存及編輯後重新選擇驗證。
- [x] 分數更新不修改評分設定檔，舊檔及損壞紀錄不妨礙其餘設定選擇；以保存重開及錯誤情境驗證。

## 阻擋

- [03：從完整對局計算設定棋力分數](03-rating-report.md)。

## 驗證證據與限制

- `tests.ui.test_profile_selector` 使用實際應用程式點擊與暫存比較結果，建立 32 條受控開局、64 局完整批次，確認選擇視窗顯示正式分數、真實勝和敗、來源及搜尋條件。
- 相同內容另存共用分數，修改權重後未評分；重新開啟應用程式、加入損壞比較紀錄及改變搜尋深度後，檢查載入、條件隔離與設定檔位元組未改變。既有選擇及損壞設定檔事件測試一併通過。
- 未執行正式長對局；上述受控棋局為軟體驗證，不構成棋力證明。

## 人工測試

在真人或批次設定中開啟評分設定選擇，選擇設定並點「棋力明細」；查看分數、局數、搜尋條件與來源。變更搜尋條件後重新開啟，可查看對應條件下的未評分或分數。
