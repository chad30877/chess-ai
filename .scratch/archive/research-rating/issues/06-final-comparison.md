# 06：對選定候選完成雙基準比較

## 上層規格

[組合研究與設定棋力分數](../spec.md)。

狀態：已完成。

## 要交付的行為

研究者在短對局後決定最多五個候選，能分開對 stable 和純子力進行完整共同開局比較，並查看、沿用或續跑已保存結果。

## 驗收條件

- [x] 使用者可凍結最多五個候選並分別預覽各候選對兩個基準、每基準 32 條開局線與 64 局；以公開流程驗證。
- [x] 每個完整比較保留固定搜尋條件、交換黑白、逐開局配對與回放，兩個基準的分母分開；以短型測試資料驗證保存及報告。
- [x] 對完全相符的既有結果可追溯並沿用，條件或設定不同不混入；以既有及不相符紀錄驗證。
- [x] 停止後可重開續跑未完成對局，保留已提交棋局及未完成量；以中斷與重開驗證。

## 驗證證據與限制

- `tests.test_final_comparison` 以可控來源驗證凍結與重開、最多五個、兩基準各 32 條線及 64 局；檢查同源既有計畫及單基準沿用，並排除不同開局與截斷條件。
- `tests.test_screening` 的應用程式事件由短對局候選選定、凍結、預覽至返回，確認不自動開始；`tests.test_learned_comparison` 以真實短對局驗證兩基準分開、搜尋條件、配對、回放、停止及重開續跑。
- 自動測試使用小型局面，未實際執行正式 64 局或五個候選；正式研究由使用者選擇啟動。
