## What to build

從棋譜實際使用的評分設定建立可編輯草稿；調整既有設定時，回放分數即時更新，並能將結果另存為新的評分設定檔。

## Acceptance criteria

- [ ] 編輯起點是棋譜保存的實際評分設定。
- [ ] 現有可調項依類別收合，預設展開已啟用項；不提供新增評分項的流程。
- [ ] 修改設定時，當前局面的靜態總分與分項貢獻立即更新。
- [ ] 可為草稿命名並另存為新設定檔；不覆寫來源檔或棋譜保存的設定快照。
- [ ] 放棄未保存的草稿後，來源設定仍保持不變。
- [ ] 另存的設定檔可重新載入，且能重現保存前看到的評分結果。
