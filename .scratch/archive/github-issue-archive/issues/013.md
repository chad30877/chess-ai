## 要完成的行為

使用者在真人對 AI 設定 Alpha-Beta 搜尋 worker 數；同一公開搜尋 API 使用能跨核心的 CPU worker 計算，縮短單步搜尋等待。

## 驗收條件

- [x] 從公開搜尋 API、玩家建立到真人對 AI 設定，正整數 worker 設定實際生效；worker 數 1 保留相容與基準用途。
- [x] 先量測現有深度 5 基準，再評估程序根分枝等方案；交付確實可跨核心的執行方式，不能只把工作移到一般 Python 背景 thread。
- [x] 協調端若參與搜尋也計入 CPU 計算 worker 上限；可派分枝數與平台限制如實處理，不按 CPU 數任意縮減使用者的搜尋設定。
- [x] 分派完整棋盤歷史與原根深度資訊，保留將死、和棋、評分視角、完成深度與輸入棋盤隔離；程序評分器不支援時明確報錯。
- [x] 逾時／取消回傳既有契約允許的結果；停止、換局與離開後清理工作，舊結果不套入新棋局；worker 故障能結束並回報。
- [x] 真人棋譜保存實際搜尋 worker 條件，舊棋譜仍可讀取。
- [x] 以公開搜尋與即時對局流程驗證重要行為，加入有界真實 Windows spawn 案例；不要求與單 worker 選步或統計逐項相同。
- [x] 人工選 worker 數 2 以上完成 AI 落子，再於搜尋中停止或換局，確認介面回應、紀錄條件與程序清理。
