## What to build

在真人對局中選擇 Alpha-Beta 對手與一份已保存的評分設定檔，並能設定搜尋深度。

## Acceptance criteria

- [ ] 真人對局可選擇 Alpha-Beta；Random 與 Greedy 仍可使用。
- [ ] 評分設定檔選擇器列出已保存設定，初始預選 stable.json。
- [ ] Alpha-Beta 使用所選評分設定；固定深度預設為 2，使用者可調整深度。
- [ ] 完成對局或保存棋譜時，記錄實際評分設定檔內容與搜尋深度。
- [ ] 對局流程維持合法落子、終局判定及既有真人操作行為。
