## 驗收條件

- [x] 用可重現的同局連續搜尋案例比較現況與隔離的保留實驗，量測有效命中、耗時及容量代價。

- [x] 交付保留或延後的建議及證據；若值得實作，描述所需獨立規格，不在本票正式啟用跨搜尋快取。
