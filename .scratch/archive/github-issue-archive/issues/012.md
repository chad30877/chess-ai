## 要完成的行為

每次 Alpha-Beta 搜尋都使用有界置換表；容量滿時依搜尋價值淘汰，真人對 AI 與既有評分比較取得有限預設值，紀錄保存實際容量設定。

## 驗收條件

- [x] 搜尋設定可指定正整數的最大表項目數，省略時也有有限預設值；實際表項數不超過所定義上限。
- [x] 同鍵更新與滿額淘汰均考慮搜尋深度、EXACT／LOWER／UPPER 及世代新舊；不靠滿額後清空整表。
- [x] 透過公開置換表行為與公開搜尋 API 驗證容量、保留偏好、滿額後可繼續搜尋，以及歷史／將死／棋盤隔離語意。
- [x] 相鄰兩次搜尋不共用舊評分；同次迭代仍可重用資料，關閉置換表的既有行為可用。
- [x] 既有玩家建立、評分比較共同條件及實際設定快照傳遞容量；舊紀錄仍可讀取。
- [x] 記錄容量單位與選定預設值的依據，說明項目上限不等同程序樹記憶體上限。
- [x] 人工以小容量連續搜尋，再查看保存設定與舊紀錄；更新必要文件與簡單測試說明。
