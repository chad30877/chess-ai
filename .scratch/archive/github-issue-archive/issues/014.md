## 要完成的行為

一般批次可讓雙方選 Alpha-Beta，分別設定同時對局數與每次搜尋 worker 數；每場搜尋使用所選多核心條件，完成即保存。

## 驗收條件

- [x] 一般批次可選 Alpha-Beta 對 Alpha-Beta，並使用既有評分設定、固定深度、搜尋 worker 與有界置換表條件；既有其他策略仍可執行。
- [x] UI 與批次服務都區分同時對局數及搜尋 worker 數；沿用既有外層有效值規則，不新增按兩者乘積限制 CPU 的規則，也不因多場並行而強制內層 worker 數為 1。
- [x] 每場結果到達即保存並更新進度；保存雙方實際評分、搜尋 worker 與置換表條件，舊批次可讀取。
- [x] 一般批次暫停／繼續沿用落子邊界及場間等待語意；停止、錯誤或保存失敗時清理內外層工作並保留可讀的已發布前綴。
- [x] 以有界 Windows spawn 案例跑至少兩場與每次至少兩個搜尋 worker，驗證逐場發布、停止和故障，不只模擬 executor 呼叫。
- [x] 驗證超額派工設定沒有被新增的 CPU 乘積限制縮減；以有限工作量執行，不要求效能線性提升。
- [x] 人工跑少量有限手數的 Alpha-Beta 對戰，完成一場即回放，再測多場在途時停止及保存結果。
