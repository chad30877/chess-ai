# 學習實驗導覽與操作改善：設計規格

狀態：Q1～Q18 的設計共識及[10 張工作票](README.md)已完成實作與整合驗收並歸檔；各票記錄實際證據及限制。

## 使用者提出的問題

- 希望顯示目前所在頁面，例如「學習實驗 > 教師先導 > 教師標記」。
- 按下教師標記後會等待一陣子。
- 不理解棋子位置學習的用途。
- 五個單群組難以操作，不知道如何開始。
- 要進入候選比較，必須沿多個頁面一直點下去。

## 已確認決策

### Q1：依操作目的進入

使用者已接受學習實驗首頁先選擇本次操作目的，例如接續學習、比較候選、查看結果及建立新實驗。已有成果的使用者不必為了比較而走過準備頁。主功能入口見 Q15，資料選擇與缺少前置成果的呈現見 Q6、Q8。

### Q2：位置與流程進度分開呈現

使用者已接受頂部顯示可點擊、可返回上層的位置路徑，流程進度另外以精簡的階段狀態呈現。路徑不以先前點過的頁面串成假層級；主功能及子頁關係見 Q15。

### Q3：合併單群組學習入口

使用者已接受將棋子位置與五個單群組合併為「評分權重學習」入口。使用者勾選想學習的評分項群組再開始訓練，每個群組各自產生結果；組合訓練另外呈現。合併的是操作入口，不將多個群組的獨立訓練誤當成聯合訓練。群組選擇與預設值見 Q10、Q11；既有單組成果納入 Q6、Q7 的查找範圍，結果呈現見 Q17。

### Q4：直接進入候選與比較紀錄

使用者已接受進入「比較候選」即可看到已有候選並勾選比較對象，同頁提供既有比較紀錄，可接續未完成對局或查看結果，不必經過組合頁。成果選擇及候選來源範圍見 Q6、Q7；比較用途與工作量見 Q12，恢復與失敗處理見 Q14、Q18。

### Q5：載入立即回應並保留返回

使用者已接受點擊教師標記後立即顯示頁面及「載入已保存標記…」，載入期間仍可返回，完成驗證後才開放續跑與學習。其他讀取較慢的頁面採相同行為。此決策涵蓋讀取期間的回應；已開始執行的任務在離開頁面時的行為見 Q9。

### Q6：以清單選擇資料與成果

使用者已接受資料與成果採可直接選取的清單，顯示可讀名稱、日期與狀態，記住上次選擇，不再默默切換成最近修改的一份。使用者應能直接找到較早已完成的成果，即使之後另有未完成工作。名稱見 Q16，候選按來源及群組篩選見 Q7，原選擇失效見 Q18。

### Q7：跨來源查找所有可比較候選

使用者已接受預設列出所有可比較的候選，包含舊棋子位置學習、單群組及組合成果，並可依來源、群組篩選。不同訓練資料算出的教師誤差分開呈現，不混成同一排名；棋力比較使用共同對戰條件。此決策擴大候選查找範圍，不放寬組合訓練所需的來源相容性。

### Q8：缺少前置成果時仍可進頁

使用者已接受未滿足前置條件時頁面仍可開啟，顯示缺少的成果及可直接前往補足的操作，只停用目前無法執行的開始按鈕。例如教師標記未完成時，學習頁顯示狀態並提供「前往接續標記」；已有成果仍可查看。

### Q9：切頁不停止已開始的任務

使用者已接受教師標記、訓練或對戰任務執行中仍可切頁瀏覽，任務不因切頁而停止；固定顯示簡短進度及「返回任務／停止」。正在使用的同一份資料與設定不可修改，既有成果仍可瀏覽。同時執行與關閉重開行為見 Q13、Q14。

### Q10：以群組選擇開始學習

使用者已接受列出棋子位置、兵形、活動力、王安全及協調五個群組，首次預設全選，可取消個別群組；開始按鈕顯示實際選取數量，例如「開始學習 5 個群組」。各組自動執行既有三種訓練強度並依既有規則選定候選，分別呈現成果，不要求使用者先選擇或理解弱／中／強。

### Q11：新建與續跑分開

使用者已接受既有訓練固定依原條件續跑，不讓畫面上新勾選的群組看似會套入舊任務。想增加群組或更改條件時使用「以此建立新訓練」，保留原有成果。可調條件仍以既有能力為範圍，不因此新增訓練參數編輯器。

### Q12：先選比較用途並顯示工作量

使用者已接受主要提供快速篩選與完整比較，開始前列出候選、基準及總局數，沿用現有研究條件與前置要求；原始設定與學習設定對照保留獨立入口。快速篩選每候選 16 局，篩選後完整比較每候選 128 局；三個候選分別為 48 與 384 局。不能把這些數字套用到不同角色或基準配置的一般共同開局比較。

### Q13：一次一項耗時任務

使用者已接受教師、訓練、比較一次只執行一項耗時任務，任務內既有的並行能力保留。執行期間可以瀏覽成果及準備其他設定；其他開始按鈕顯示目前執行中的任務。此輪不新增多任務排程或排隊功能。

### Q14：關閉停止保存，重開手動接續

使用者已接受有任務執行時，關閉程式前提供停止並儲存後離開或繼續執行的選擇；確認離開後等待停止及保存完成。下次開啟顯示未完成任務，由使用者手動選擇續跑，不自動啟動耗時工作。保留現有恢復粒度：已完成部分保留，未完成求解或當局重算。教師先導目前無法續跑，提示需重新量測，此輪不擴充教師先導續跑能力。

### Q15：固定主功能及頁面層級

使用者已接受上方固定「資料準備｜教師評分｜評分權重學習｜比較候選」四個入口，各頁另有可返回的位置路徑。教師先導與教師標記是教師評分下的不同子頁；單群組與組合是評分權重學習下的不同子頁。選定資料後另外呈現該資料的階段完成狀態，不把研究順序當成頁面父子關係。

### Q16：自動名稱與自行改名

使用者已接受以日期與用途產生可讀名稱，例如「10/29 棋子位置學習」，清單另列來源與狀態，並允許修改顯示名稱。舊成果也自動產生可讀名稱，不要求逐份人工整理。改名僅用於辨識成果，應保護既有快照、候選身分與保存結果。

### Q17：摘要先呈現成果及下一步

使用者已接受學習結果先顯示群組完成狀態、學習前後教師誤差及「比較候選／另存設定／用於對戰」。權重明細與訓練診斷收進詳細資訊。未進行對戰者顯示尚未比較，不把教師誤差改善稱為棋力提升。比較結果呈現勝和敗、對局數，以及有依據的設定棋力分數或暫估狀態。

### Q18：失效資料與失敗任務保留明確恢復入口

使用者已接受資料被移走或損壞時指出哪份資料不可用，提供重新讀取或選擇其他成果，不默默換用另一份。任務失敗保留已保存進度，依實際能力提供重試或續跑；直接呈現簡短原因，詳細錯誤可展開。不將無法恢復的教師先導標成可續跑。

## 頁面結構與操作摘要

```text
學習實驗（按目的進入、接續任務、查看成果）
├─ 資料準備
├─ 教師評分
│  ├─ 教師先導
│  └─ 教師標記
├─ 評分權重學習
│  ├─ 單群組學習（新建／既有訓練）
│  └─ 組合（沿用直接組合與聯合訓練）
└─ 比較候選
   ├─ 候選清單（快速篩選／完整比較／原始與學習設定對照）
   └─ 比較紀錄（續跑／結果）
```

- 主功能入口負責直接前往目的地；位置路徑負責返回上層；資料階段狀態只反映已選來源的成果。全來源候選清單不暗示所有候選共用同一套資料或完成進度。
- 來源清單使用可讀名稱、日期與狀態，選擇依保存身分識別，不能因顯示名稱相同或改名而選錯。既有成果可直接開啟，不要求重新量測、標記或訓練。
- 開啟較慢頁面先呈現載入狀態，期間可返回。離開後舊讀取結果不得將使用者拉回原頁或覆蓋新選擇。資料驗證完成前不開放依賴該結果的執行操作。
- 教師、訓練、比較共用一項執行中任務的使用者視角，任務進度與停止入口跨頁可見；執行頁的切換不代表停止。停止及關閉保存期間仍呈現處理狀態，待安全結束才釋放任務或退出。
- 群組首次全選，零選取時不可開始；開始按鈕反映實際群組數。新建、續跑及以此建立新訓練的條件不能混用。
- 候選查找涵蓋所有既有學習成果，不沿用舊盤點僅回傳前十名的限制。舊獨立棋子位置格式以唯讀轉接處理；未完成報告的成果可列出狀態，但不能充當可比較候選。
- 比較前置條件、篩選規則、對戰預算、共同開局與來源相容性沿用現有研究規則。總局數依實際用途、候選及基準計算；續跑另呈現已完成與剩餘工作。
- 主畫面只放辨識、決策及操作所需資訊。權重、條件、診斷及詳細錯誤按需展開，不以大量教學文字補救不清楚的操作。

## 驗收情境與驗證方式

以下為後續實作的驗收依據，目前均未宣稱已通過。主要以應用程式事件整合驗證，配合必要畫面檢查；教師使用既有外部 UCI 邊界替身與小資料，不啟動正式長實驗。人工步驟用於重現，不自動成為等待使用者驗收的阻擋。

| 情境 | 可判定成果 | 驗證方式 |
| --- | --- | --- |
| 已有成果，今天只想比較 | 從學習實驗直接進候選清單，途中不經教師或組合頁 | UI 事件操作及畫面檢查 |
| 從不同入口進同一子頁 | 位置路徑一致且可回正確上層 | UI 事件導覽及返回驗證 |
| 昨日完成、今日另有未完成訓練 | 能直接選昨日成果，重開保持原選擇 | 保存兩份不同狀態成果後操作及重開 |
| 不同來源與舊棋子位置成果 | 所有有效候選皆可找到，來源篩選正確 | 混合新舊格式與超過十份候選的整合資料 |
| 改名與同名成果 | 改名後仍識別原成果，保存研究資料可照常驗證 | 改名、重開、核對候選身分及原快照 |
| 開啟大量教師標記 | 完整讀取完成前即可看到載入狀態並返回 | 控制外部讀取延遲的事件驗證及既有資料短量測 |
| 載入未完就切換來源 | 舊讀取結果不覆蓋目前頁面或選擇 | 交錯讀取完成順序的事件驗證 |
| 尚未完成教師標記 | 學習頁可開啟並直達缺少的前置工作，不能誤啟動訓練 | 不完整標記資料的操作驗證 |
| 新建單群組學習 | 實際執行群組與畫面選取一致 | 由 UI 勾選至公開學習入口，核對保存快照與結果 |
| 舊任務續跑及另建 | 續跑保持原條件，另建才採用新群組 | 停止、改選、另建及核對兩份成果 |
| 任務執行中切頁 | 原任務持續，進度及停止入口可用 | 小任務跨頁、返回與停止的事件驗證 |
| 執行中啟動另一項任務 | 第二項耗時任務不會啟動 | 跨教師、訓練、比較入口的互斥操作驗證 |
| 關閉有任務的程式 | 確認停止後完成保存才退出 | 關閉取消、確認及重開保存結果驗證 |
| 重開未完成工作 | 不自動執行，按續跑只補缺少完成單位 | 標記、訓練及比較的停止重開整合驗證 |
| 停止教師先導 | 呈現需重新量測，沒有虛假續跑操作 | 先導停止狀態的 UI 事件驗證 |
| 比較三個候選 | 快速篩選顯示 48 局，雙基準完整比較顯示 384 局 | 實際候選選取與建立比較計畫驗證，不跑完全部對局 |
| 只有教師誤差改善 | 結果不宣稱棋力提升，仍可查看詳情與使用成果 | 只有學習報告的成果畫面及操作驗證 |
| 保存資料失效或任務失敗 | 指明失效來源，不偷換成果，保留可恢復進度 | 檔案缺失／損壞及可控制工作失敗的整合驗證 |
| 最小視窗及大量清單 | 導覽、主操作、進度與狀態保持可讀可操作 | 既有最小視窗與預設視窗的畫面及捲動檢查 |

人工重現路徑：開啟學習實驗後直接比較舊候選；從學習頁選一個群組建立訓練；執行中切頁查看舊成果；返回並停止，關閉重開後手動續跑；最後改名一份成果並再次開啟確認選擇。

## 本輪範圍

此輪改善既有學習實驗的導覽、等待回饋、成果查找、操作語意及任務生命週期。沿用現有教師、學習、校準、篩選及對戰規則，不重跑正式研究，不以此宣稱棋力提升。明確不增加多任務排程、教師先導續跑、任意新訓練參數編輯或研究資料刪除能力。既有成果及研究身分須保持可追溯。

## 現況證據

- `ui/learning_view.py`、`ui/teacher_view.py`、`ui/label_view.py` 將資料準備、教師先導及教師標記串接為相鄰頁入口，沒有共用位置路徑。
- `engine/learning/training.py` 的棋子位置學習調整既有位置表的中局與殘局整體倍率，不是重新學習每格數值。
- `engine/learning/group_training.py` 支援任選一到五個群組獨立訓練，包含棋子位置；它依賴完整教師標記，不依賴先完成獨立的棋子位置學習。
- `ui/learning_view.py` 的教師標記動作先呼叫 `labels.open()`，完成才切換頁面；`engine/learning/labeling.py` 會讀取並驗證逐局面記錄。唯讀單次量測目前 5,809 筆保存標記的 `load_labeling()` 約 1.014 秒。此數字不是完整 UI 點擊耗時或冷快取基準，也未證明這是唯一瓶頸。
- 共同開局比較可從群組或組合結果進入；候選盤點則藏在組合頁之後。兩者呈現不同範圍的候選與比較流程，本輪依 Q4、Q7、Q12 整理入口。
- `engine/learning/candidate_inventory.py` 目前只盤點同一次五組訓練及其衍生組合，依驗證誤差取前十名，沒有收錄舊棋子位置獨立訓練；Q7 的全來源查找需要擴充現有能力。
- `ui/teacher_view.py`、`ui/label_view.py`、`ui/group_training_view.py` 各自載入最近修改的保存資料；最近修改不代表已完成或與使用者目前選擇相符。Q6 要求明確選取及記住選擇。
- 學習任務目前保存在頁面物件中，多數階段切換會被阻擋；回應用程式首頁卻會保留工作繼續執行。比較使用一般批次執行頁，離開會確認並停止。Q9 要求統一學習實驗相關任務的切頁行為。
- `ui/group_training_view.py` 的續跑使用舊快照，不採用畫面上新勾選的群組；新增群組必須建立新訓練。`engine/learning/training.py` 的弱／中／強是偏離原始權重的懲罰強度，各組自動跑三種並依驗證結果選定候選，不是棋力或執行時長選項。
- 快速篩選為每候選對 stable 共 16 局；篩選後完整比較為每候選對純子力與 stable 共 128 局。既有一般共同開局比較另含原始／學習角色選擇，不應把所有入口的局數概括為同一值。
- 正常關閉程式會停止任務並等待保存。教師標記、單群組學習及比較可從已保存的完成單位續跑；未完成的求解或當局會重算。教師先導目前不能續跑，重新執行須建立新先導。
- `ui/group_training_view.py` 已有群組狀態、原始與學習設定的教師誤差、權重變動及另存／真人對戰／比較入口，可重整既有結果呈現。設定棋力分數來自對 stable 的對戰，不能由教師誤差換算。
- 舊獨立棋子位置訓練已有凍結設定與來源驗證，可透過唯讀格式轉接納入候選查找，不需重訓或改寫原成果；尚未完成報告者不可當成完成候選。學習資料與成果目前沒有自訂顯示名稱，原快照及凍結設定有身分交叉驗證，新增命名須保護既有研究身分。
