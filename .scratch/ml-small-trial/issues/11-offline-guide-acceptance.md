# M11：交付附實際截圖的離線教學並完成端到端驗收

## 父規格

[規格：可操作、可續跑的 ML 小規模權重試驗與共同開局驗證](https://github.com/chad30877/chess-ai/issues/26)

## 要建置的內容

交付使用者可離線閱讀的 HTML 教學，從目的找到對應控制項，並用實際應用程式完成單群組、組合、停止續跑及共同開局驗證。不是在最後一票才補必要 UI；各切片應已可操作。

## 驗收條件

- [ ] HTML 與所需資源可離線開啟，包含實際版本截圖及編號重點標示，不用模擬畫面冒充已完成操作。
- [ ] 教學涵蓋資料、教師先導與預算選擇、標記篩選、校準、單群組、活動力＋王安全、直接組合／聯合訓練、誤差解讀、另存、對戰及停止續跑。
- [ ] 提供「想調什麼 → 使用哪個控制項」的查找方式，說明改動方向、代價與結果位置；清楚區分評分項群組、搜尋演算法、教師節點預算、對戰深度、同時場數、搜尋 worker 及 TT 表項數。
- [ ] 由 Agent 使用真實 UI 串接實際來源與 Stockfish，以短流程完成至少一組學習與組合輸出後送入共同開局比較；核對停止／關閉續跑、原始快照、逐手進度、結果及回放一致。短流程與完整實驗的證據分開記錄。
- [ ] 交付可依八小時政策分次執行正式資料／標記／五組及預定組合、每候選 64 局實驗的功能與操作說明；完整研究由使用者交付後執行，不是本票關閉前必須跑滿的工作。未執行的實驗如實列出，不能用短局驗收宣稱完整研究完成或棋力提升。
- [ ] 不增加深度 5、有償算力或自動重啟範圍；發現問題在對應行為修復並做必要回歸，不為靜態文案、截圖數量或常數新增測試。
- [ ] 更新簡短測試說明及目前開發計畫，保存驗證證據與限制。
- [ ] 完成實作與文件的繁體中文 Git commit。

## 執行與結案

一般 `/implement` 由 Agent 完成必要驗證並記錄證據，接著依專案 tracker 流程同步 GitHub 與本機票、索引及開發計畫，提交並關閉本票，最後讀回核對。供使用者重現的操作方式不是另一次必要人工驗收；不例行等待使用者操作或再次同意關票。真實失敗或缺少必要資源時先修復，無法完成才保留未勾選、開啟狀態並說明阻礙。

軟體驗收使用足以涵蓋行為的短流程；八小時停止以可控制時鐘驗證。正式完整資料與長時間對戰由使用者於交付後分次執行，不能把短流程結果宣稱為完整研究或棋力提升。
