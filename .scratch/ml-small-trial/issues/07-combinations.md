# M07：自選群組直接組合、聯合訓練與搭配效果比較

## 父規格

[規格：可操作、可續跑的 ML 小規模權重試驗與共同開局驗證](https://github.com/chad30877/chess-ai/issues/26)

## 要建置的內容

使用者可勾選多個群組，先建立單組學習權重的直接組合，再進行聯合訓練，分別查看與另存結果；預設提供活動力＋王安全的四設定搭配驗證。

## 驗收條件

- [x] UI 可明確勾選群組，預覽實際開關、權重與候選數，不自動展開全部組合；不接受不相容資料／尺度的單組結果默默混合。
- [x] 直接組合保留各單組已學權重；聯合訓練同時調整所選群組，另建候選身份及結果。兩者都可另存完整合法設定。
- [x] 固定權重比較純子力、加活動力、加王安全、兩者皆加，呈現兩種背景下王安全的誤差增量；四設定使用相同資料及階段規則，不把分別重訓結果冒充固定權重對照。
- [x] 活動力＋王安全不因王安全單組排名低取消。任意選定組合沿用校準、非負訓練、驗證挑選、測試凍結、八小時總預算與續跑規則。
- [x] 新組合若沿用已查看的測試組，清楚保留資料使用脈絡，不宣稱全新未見驗證；不使用測試分數反覆選訓練參數。
- [x] 結果區分直接組合、固定權重增量及聯合重訓，不宣稱加法評分器新增交互特徵；保留可用於既有比較的完整設定。
- [x] 高層 UI／訓練／保存測試驗證所選群組、直接組合值、聯合訓練只改選定權重與中斷重開；由 Agent 走通活動力＋王安全的組合流程並記錄證據。
- [x] 更新簡短測試說明及目前開發計畫，保存驗證證據與限制。
- [x] 完成實作與文件的繁體中文 Git commit。

## 執行與結案

一般 `/implement` 由 Agent 完成必要驗證並記錄證據，接著依專案 tracker 流程同步 GitHub 與本機票、索引及開發計畫，提交並關閉本票，最後讀回核對。供使用者重現的操作方式不是另一次必要人工驗收；不例行等待使用者操作或再次同意關票。真實失敗或缺少必要資源時先修復，無法完成才保留未勾選、開啟狀態並說明阻礙。

軟體驗收使用足以涵蓋行為的短流程；八小時停止以可控制時鐘驗證。正式完整資料與長時間對戰由使用者於交付後分次執行，不能把短流程結果宣稱為完整研究或棋力提升。
