# M05：完成單群組校準、學習、獨立誤差評估與另存

## 父規格

[規格：可操作、可續跑的 ML 小規模權重試驗與共同開局驗證](https://github.com/chad30877/chess-ai/issues/26)

## 要建置的內容

先以棋子位置群組從 UI 走通完整學習流程：校準教師、訓練三個候選、驗證挑選、凍結後測試、查看原始與新權重並另存可用設定。這是最小可驗收的 ML 成果。

## 驗收條件

- [x] 只從訓練組依固定 stable 評分計算逐盤等權、無截距的共用倍率，保存參照、殘差及穩定性診斷；零分母、非正／非有限值或診斷異常不能產生誤導的成功排序。
- [x] 特徵精確對應正式評分器及相同階段混合；固定棋子價值、子力倍率與開關，僅學所選群組的非負中殘局權重。
- [x] 使用逐盤等權非負最小平方與標準化偏離原始權重懲罰，固定弱／中／強三種強度；強度、尺度、版本、容差與選擇順序在開始前保存。零權重採正絕對尺度，不設統一百分比硬上限。
- [x] 驗證組選定後凍結完整候選，測試組只評估一次；重開顯示已保存結果。逐盤平均 MAE 與各階段分層並列純子力、原始同組、學習同組及 stable；空組顯示無資料而非零誤差。
- [x] UI 可查看原始／新權重及誤差、另存完整合法設定，既有比較與回放可載入；學習無改善也是有效結果，不強制宣稱成功提升棋力。
- [x] 以完成候選保存進度，單次訓練最多八小時；停止／到時中止未完成求解並清理程序，重開只重跑未完成候選，不把部分解宣告完成。
- [x] 從 UI／實驗入口用可手算資料驗證校準、非負約束、固定子力、評分一致、驗證挑選、測試凍結與停止續跑；不測內部矩陣或求解器呼叫形式。
- [x] 由 Agent 透過 UI 事件整合測試或實際操作，完成一組學習、另存並載入對戰。
- [x] 更新簡短測試說明及目前開發計畫，保存驗證證據與限制。
- [x] 完成實作與文件的繁體中文 Git commit。

## 執行與結案

一般 `/implement` 由 Agent 完成必要驗證並記錄證據，接著依專案 tracker 流程同步 GitHub 與本機票、索引及開發計畫，提交並關閉本票，最後讀回核對。供使用者重現的操作方式不是另一次必要人工驗收；不例行等待使用者操作或再次同意關票。真實失敗或缺少必要資源時先修復，無法完成才保留未勾選、開啟狀態並說明阻礙。

軟體驗收使用足以涵蓋行為的短流程；八小時停止以可控制時鐘驗證。正式完整資料與長時間對戰由使用者於交付後分次執行，不能把短流程結果宣稱為完整研究或棋力提升。
