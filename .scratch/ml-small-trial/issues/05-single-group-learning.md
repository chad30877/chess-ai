# M05：完成單群組校準、學習、獨立誤差評估與另存

## 父規格

ML 小規模權重試驗規格草稿；發布時替換為父規格 issue 連結。狀態：待核准，尚未發布。

## 要建置的內容

先以棋子位置群組從 UI 走通完整學習流程：校準教師、訓練三個候選、驗證挑選、凍結後測試、查看原始與新權重並另存可用設定。這是最小可驗收的 ML 成果。

## 驗收條件

- [ ] 只從訓練組依固定 stable 評分計算逐盤等權、無截距的共用倍率，保存參照、殘差及穩定性診斷；零分母、非正／非有限值或診斷異常不能產生誤導的成功排序。
- [ ] 特徵精確對應正式評分器及相同階段混合；固定棋子價值、子力倍率與開關，僅學所選群組的非負中殘局權重。
- [ ] 使用逐盤等權非負最小平方與標準化偏離原始權重懲罰，固定弱／中／強三種強度；強度、尺度、版本、容差與選擇順序在開始前保存。零權重採正絕對尺度，不設統一百分比硬上限。
- [ ] 驗證組選定後凍結完整候選，測試組只評估一次；重開顯示已保存結果。逐盤平均 MAE 與各階段分層並列純子力、原始同組、學習同組及 stable；空組顯示無資料而非零誤差。
- [ ] UI 可查看原始／新權重及誤差、另存完整合法設定，既有比較與回放可載入；學習無改善也是有效結果，不強制宣稱成功提升棋力。
- [ ] 以完成候選保存進度，單次訓練最多八小時；停止／到時中止未完成求解並清理程序，重開只重跑未完成候選，不把部分解宣告完成。
- [ ] 從 UI／實驗入口用可手算資料驗證校準、非負約束、固定子力、評分一致、驗證挑選、測試凍結與停止續跑；不測內部矩陣或求解器呼叫形式。
- [ ] 人工完成一組學習、另存並載入對戰；更新說明與計畫，提交 Git commit。
