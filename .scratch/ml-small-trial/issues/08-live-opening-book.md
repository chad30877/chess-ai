# M08：一般與真人對戰可選開局庫並在離庫後搜尋

## 父規格

[規格：可操作、可續跑的 ML 小規模權重試驗與共同開局驗證](https://github.com/chad30877/chess-ai/issues/26)

## 要建置的內容

在一般對戰與真人對 AI 的 Alpha-Beta 路徑提供開局庫開關、手數上限與可重現保存；收錄走法用完後繼續正常搜尋。不依賴 ML 即可單獨驗收。

## 驗收條件

- [ ] 取得並固定 Lichess 具名開局資料版本、雜湊及 CC0 授權，驗證完整合法序列；UI 可選擇啟用，資料缺失／損壞可見，不靜默換來源。
- [ ] 從目前局面不同合法收錄走法等機率選擇；同一走法出現於多個開局名稱不增加權重，不假造勝率資料。
- [ ] 預設最多 12 手、UI 可調；首次查無走法或達上限後該局永久離庫，之後使用 Alpha-Beta。真人落子也更新離庫狀態，新局才重置。
- [ ] 保存來源、種子、實際開局走法與離庫狀態，搜尋棋盤保持完整歷史，記錄可回放；未啟用開局庫時保持既有行為。
- [ ] 單局及一般批次使用相同政策；停止或重新開始不讓舊工作結果落入新局，保持既有逐手進度。
- [ ] 從對戰／UI 入口驗證去重、種子重現、手數界線、離庫後不回庫、真人偏離、保存回放與停止；不以少量抽樣頻率硬斷言機率。
- [ ] 人工開啟開局庫並觀察超過上限後搜尋，更新說明與計畫並提交 Git commit。
