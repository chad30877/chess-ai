# M06：五個單群組共用預算學習與完整結果比較

## 父規格

ML 小規模權重試驗規格草稿；發布時替換為父規格 issue 連結。狀態：待核准，尚未發布。

## 要建置的內容

讓使用者一次選擇五個單群組，沿用相同資料與教師尺度，分組完成訓練、續跑與誤差比較，選取需要的學習設定。

## 驗收條件

- [ ] 棋子位置、兵形、活動力、王安全、協調均可獨立學習，合計涵蓋 32 個現有位置權重；未選群組保持關閉，零初始權重仍能變正。
- [ ] 各組共用同一資料分組、教師標記與校準倍率，不因切換群組重估；原始單群組與學習設定具有相同階段規則。
- [ ] 所有選定群組及三種強度共用整次八小時預算；完成候選逐個保存，停止、關閉及到時後只重跑未完成部分，不能每組重開八小時計時。
- [ ] 結果按群組並列原始／學習的驗證與測試 MAE、相對純子力與 stable 的差異、各階段與有效樣本量，顯示已完成／失敗／未完成，不將排序宣稱最強。
- [ ] 驗證與測試皆改善者可標示為優先對戰觀察，不設改善百分比硬門檻；未勝過 stable 不禁止保存或進入組合，無改善也可輸出完整結果。
- [ ] 使用者可從結果選取候選、查看權重差異、另存與重新載入。各組測試結果遵守凍結後一次評估，改條件另建實驗並保留來源關係。
- [ ] 高層流程測試涵蓋多群組共用預算、跨群組續跑、零權重學習、群組隔離及部分失敗；不用增加單純常數測試。
- [ ] 人工跑兩組後停止並續跑其餘組，確認結果不重複；更新說明與計畫，提交 Git commit。
