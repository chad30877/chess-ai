# M01：從 UI 辨識、選用與另存單群組設定

## 父規格

[規格：可操作、可續跑的 ML 小規模權重試驗與共同開局驗證](https://github.com/chad30877/chess-ai/issues/26)

## 要建置的內容

讓使用者從既有設定選擇與回放評分入口，辨識純子力與五個單群組、查看實際內容並另存合法設定，用於現有真人對戰與比較。不需要先完成 ML 即可展示。

## 驗收條件

- [ ] 提供純子力，以及子力分別搭配棋子位置、兵形、活動力、王安全、協調的五組學習預設；各組固定相同階段規則與棋子價值，不把既有累加範例誤當單群組。
- [ ] 設定選擇呈現中文名稱、實際群組與分階段狀態；既有 stable 保留原數值、關閉分階段且標示為子力＋棋子位置，不被新預設覆寫。
- [ ] 使用者能查看設定、另存完整版本化設定，再從真人對戰或評分比較載入，實際評分反映選定群組。
- [ ] 五組包含 16 個現有位置項，中殘局各一權重；棋子位置維持整組 PST 倍率，沒有擴充成每格學習。
- [ ] 透過既有 UI 事件、評分與保存／讀回流程驗證群組隔離及設定實際生效；不為名稱常數或 JSON 靜態內容增加測試。
- [ ] 人工展示選一組、查看內容、另存並開啟對戰；更新簡短測試說明及開發計畫，提交繁體中文 Git commit。
