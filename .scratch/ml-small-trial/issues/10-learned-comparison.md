# M10：學習結果接入深度三共同開局驗證與研究報告

## 父規格

ML 小規模權重試驗規格草稿；發布時替換為父規格 issue 連結。狀態：待核准，尚未發布。

## 要建置的內容

使用者從學習結果選擇候選，預覽完整對戰條件後送入共同開局比較，查看逐開局對戰結果、回放及獨立於教師誤差的研究結論。單群組先可使用，組合輸出沿用相同設定契約。

## 驗收條件

- [ ] 結果入口可選原始／學習候選與純子力主基準，另以既有 stable 作參考比較；保存來源實驗及完整設定，直接組合／聯合訓練可透過相同合法設定契約接入。
- [ ] 預覽並固定深度 3／q4、同時 4 局、每局 1 搜尋 worker、TT 4,096 筆，雙方一致。現有判和政策與手數上限保存於快照，不改成深度 5。
- [ ] 使用 32 條共同線，每候選對每個選定基準 64 局；額外 stable 比較明確增加總工作量，各基準統計分開，不誤用分母。
- [ ] 保留逐手進度、逐場保存、完整配對統計、停止／重開續跑、回放與另存；原始／學習設定身份不可因排序或顯示名稱混淆。
- [ ] 報告整體及逐開局勝和敗、完整配對／未完成量、耗時及條件，並列教師驗證／測試誤差但不混成同一指標。不把中斷算和棋，不以有限勝率宣告棋力保證。
- [ ] 高層學習結果到比較、保存及重開測試驗證設定相同、額外參考工作量、候選來源及統計；使用小型合法開局檢查流程，不在日常測試跑完整 64 局。
- [ ] 人工從學習結果進入短比較並查看回放，另提供完整對戰可分次執行的驗收方式，更新說明與計畫並提交 Git commit。

## 阻擋來源

- M06：需要完整單群組學習結果、候選身份及選用入口。
- M09：需要共同開局的比較、歷史、保存與續跑流程。

M07 不阻擋此票：組合使用相同完整評分設定契約；完整交付時再一起驗收其接入。
