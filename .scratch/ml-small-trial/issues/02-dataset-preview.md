# M02：從 UI 建立可重現的棋譜資料分組與局面預覽

## 父規格

[規格：可操作、可續跑的 ML 小規模權重試驗與共同開局驗證](https://github.com/chad30877/chess-ai/issues/26)

## 要建置的內容

使用者可選取／取得固定來源棋譜，建立學習實驗，預覽訓練、驗證、測試的實際樣本及排除數，保存後重新開啟查看。這個資料準備切片獨立於設定預設及教師程序。

## 驗收條件

- [ ] UI 提供 Lichess 2013 年 1 月標準棋資料來源與本機檔案入口；取得方式、CC0 授權、來源雜湊、種子及處理版本保存於不可變快照。大檔串流處理，錯誤可見，背景處理不凍結 UI。
- [ ] 去重棋譜後抽 500 盤，先按整盤分為 350／75／75，再每盤最多抽 12 局面；略過前 8 手，兼顧棋局階段，保留完整合法歷史。來源不足須明確報告，不重複補足。
- [ ] 同組重複局面只留一份，跨組重複從所有組排除；局面身份使用盤面、輪到方、易位與有效吃過路兵，不以回合數區別。
- [ ] 教師前先排除已終局及受將局面，保存排除原因；UI 顯示各分組盤數、局面數、階段分布與篩除統計，接受總量不足 6,000。
- [ ] 完成資料可重新開啟，變更來源、種子或處理規則建立新實驗；停止或失敗不把部分產物標成完整資料，已完成快照不受影響。
- [ ] 高層資料建立／保存／重開測試以小型棋譜驗證確定性、整盤隔離、跨組重複、有效吃過路兵身份及損壞輸入；測試不依賴下載完整公開檔案。
- [ ] 人工從 UI 建立並重開資料預覽；整理測試說明與開發計畫並提交 Git commit。
