# 03：從完整對局計算設定棋力分數

## 上層規格

[組合研究與設定棋力分數](../spec.md)。

狀態：已完成。

## 要交付的行為

研究者能在比較結果查看設定相對 stable 的分數、實際勝和敗及來源；批次完整後自動更新，歷史相容結果也可計入。

## 驗收條件

- [x] 完整對局報告以 stable 1500 分為參照，依實際勝和敗及半勝半敗平滑換算設定棋力分數；以手算資料驗證和棋、全勝與全敗。
- [x] 報告顯示真實勝和敗、有效局數、設定及對局條件，未計入虛擬對局；以公開報告核對。
- [x] 條件相符的既有完整批次及後續新完成配對可累積，完全重複確定性對局不重複計入；以保存、重開及重複紀錄驗證。
- [x] 短對局、純子力基準、不同設定內容或搜尋條件的對局不混入正式分數；以跨來源資料驗證。
- [x] 停止、失敗、截斷及不完整配對不算有效勝和敗，未完成批次不覆寫先前正式分數；以中斷續跑驗證。
- [x] 報告可區分無資料、暫估與正式分數，並說明相對 Elo 和固定開局的不確定性；以資料不足情境驗證。

## 驗證證據與限制

- 整合審查補驗：重新排序共同開局後，確定性對局不因種子變更重複計入。

- 自動測試：`tests.test_rating` 使用實際保存的共同開局批次及重開，驗證平滑分數、64 局、重複紀錄、停止後保留正式分數、缺少單色的配對、第二色受控失敗及續跑、新配對累積、不同設定與搜尋條件、純子力及截斷條件隔離。`tests.test_learned_comparison` 驗證既有比較流程。`tests.ui.test_learned_comparison` 以應用程式事件查看未評分及已保存來源明細。
- 使用可控對局失敗測試保存第一色後第二色失敗，確認失敗批次與不完整配對不列入分數；重開續跑後才計入完整配對。未執行正式長對局。

## 阻擋

無，可立即開始；使用既有可操作的比較報告入口及保存紀錄。
