## 要交付的行為

從紀錄點選棋局進入回放：SVG 棋盤、走法清單、鍵盤逐手與跳至起終點、最後一手變動格標示、局面靜態評分分項；返回紀錄恢復原批次、頁碼與選取。新舊棋譜格式皆可讀。

## 功能驗收與驗證方式

- [ ] 新舊棋譜回放的局面序列正確。驗證：API 測試沿用既有回放 fixture。
- [ ] 鍵盤操作與返回恢復位置。驗證：端到端或實際瀏覽器操作。
- [ ] 評分拆解與 engine 輸出一致。驗證：API 測試。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
