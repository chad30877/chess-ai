## 要交付的行為

伺服器持有工作登錄處；重度工作全機同時一個（以跨程序檔案鎖，pygame 開始重度工作前也取鎖）。頂端工作列以 SSE 即時顯示執行中工作並可停止；關閉瀏覽器工作繼續，關閉伺服器時停止並保存。首頁顯示進行中、可續跑（啟動時背景掃描並快取）、最近研究與紀錄及三個入口。以既有一般批次作為第一個接入的工作驗證整條路徑。

## 功能驗收與驗證方式

- [ ] 重度工作執行中再開始第二個被拒並說明佔用者。驗證：API 測試。
- [ ] 伺服器與 pygame 兩程序互搶全機鎖，只有一方取得。驗證：兩程序實測。
- [ ] SSE 斷線重連後先收到完整快照。驗證：API 測試。
- [ ] 關閉瀏覽器後工作繼續；關閉伺服器時工作停止、已完成局保存。驗證：API 測試與實際操作。
- [ ] 首頁列出可續跑工作且不阻塞頁面讀取；掃描結果在工作結束後更新。驗證：API 測試（以暫存資料目錄）。
- [ ] 讀取工作使用獨立池，重度工作執行中讀取仍可回應。驗證：API 測試。
