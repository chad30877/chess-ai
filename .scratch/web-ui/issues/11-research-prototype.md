# W11：研究頁原型與使用者確認

狀態：ready-for-agent。
阻擋來源：W02。
實作：Claude、使用者（使用者參與必要驗收）。
規格：[網頁介面](../spec.md)。
索引：[本批工作票](../README.md)。

## 要交付的行為

以假資料做可點選的研究頁與四份清單頁原型（五張步驟卡、目前使用切換、缺少前置、詳細收合）；以 design-critique 審查並由使用者試用，確認後把定案寫回本票與規格。

## 功能驗收與驗證方式

- [ ] 原型涵蓋五張卡四種狀態與分岔切換。驗證：截圖。
- [ ] 使用者試用並確認或提出修改。驗證：使用者確認（必要）。
- [ ] 定案的版面與互動寫入本票與規格。驗證：讀檔核對。
