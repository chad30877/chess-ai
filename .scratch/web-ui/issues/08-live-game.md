## 要交付的行為

設定評分設定、搜尋方式、深度、搜尋 worker 與開局庫後開始對局；棋盤點選或拖曳落子，只允許合法走法，升變可選子；AI 狀態（庫內、等待、搜尋中、暫停、終局）與落子經 SSE 即時更新；可認輸、重新開始，離開時明示保存行為。

## 功能驗收與驗證方式

- [ ] 非法走法被拒、升變四種選擇有效。驗證：API 測試。
- [ ] AI 落子經 SSE 送達且狀態序列正確。驗證：API 測試（深度 1）。
- [ ] 對局保存可在對局紀錄回放。驗證：API 測試。
- [ ] 棋盤互動元件的點選與拖曳。驗證：前端單元測試。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
