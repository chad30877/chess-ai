規格：[網頁介面](../spec.md)。

## 要交付的行為

設定基準與多份候選、共同搜尋條件、32 條共同開局線預覽或 FEN 開局集（以選檔對話框選檔）；建立權重實驗（清單或範圍輸入、實際值／百分比切換、組合預覽與上限）；結果表排序翻頁、回放候選與另存實際設定；中斷後重開只補缺局。

## 功能驗收與驗證方式

- [ ] 共同開局線預覽與 pygame 版一致。驗證：API 測試。
- [ ] 權重組合預覽數量與超限拒絕正確。驗證：API 測試。
- [ ] 停止後續跑只補缺局、原局只計一次。驗證：API 測試。
- [ ] 另存候選設定可在對戰選單使用。驗證：API 測試。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
