## 要交付的行為

對局紀錄頁以表格依日期篩選、翻頁列出比較批次、一般批次與非批次；比較批次顯示候選視角勝和敗、完整配對得分率與未完成配對；可查看基準／候選完整設定、設定差異及整批保存設定。

## 功能驗收與驗證方式

- [ ] 三種紀錄的摘要與 pygame 版相同資料一致。驗證：沿用 records／comparison catalog 測試資料的 API 測試。
- [ ] 日期篩選只限制棋局清單，統計仍涵蓋整批。驗證：API 測試。
- [ ] 無完整配對顯示「無資料」，未完成局不算和棋。驗證：API 測試。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
