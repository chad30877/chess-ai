## 要交付的行為

在回放以保存的評分設定建立草稿，按評分項群組調整權重並即時看到局面評分變化，輸入新名稱另存設定檔；不覆寫同名檔案，新設定立即出現在對戰與批次的設定選單。

## 功能驗收與驗證方式

- [ ] 草稿調整後的評分與 engine 計算一致。驗證：API 測試。
- [ ] 同名另存被拒。驗證：API 測試。
- [ ] 另存後設定清單包含新檔。驗證：API 測試。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
