# W02：設計規範與 Material 主題

狀態：ready-for-agent。
阻擋來源：W01。
實作：Claude、使用者（使用者參與必要驗收）。
規格：[網頁介面](../spec.md)。
索引：[本批工作票](../README.md)。

## 要交付的行為

使用者從 design-taste-frontend 工作畫面模式抽出的三個方向挑選一個；以 Design design-system 整理成 `docs/設計系統.md`，轉成 Angular Material 主題（深淺色、緊湊密度），套用到外殼並提供表格、表單、按鈕層級、停用說明、狀態色與識別碼複製的共用元件示範頁。

## 功能驗收與驗證方式

- [ ] 使用者選定方向。驗證：使用者確認（必要）。
- [ ] `docs/設計系統.md` 涵蓋色彩、字級、間距、密度與規格中的元件規則。驗證：讀檔核對。
- [ ] 外殼與示範頁在 1280／900、深色與淺色下截圖，design-critique 無重大問題。驗證：截圖與審查紀錄。
- [ ] 停用動作滑過顯示原因、識別碼可一鍵複製。驗證：前端單元測試。
