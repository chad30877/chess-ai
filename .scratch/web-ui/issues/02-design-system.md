## 要交付的行為

使用者從 design-taste-frontend 工作畫面模式抽出的三個方向中挑選一個，整理成 `docs/設計系統.md`，再轉成 Angular Material 主題（深淺色、緊湊密度），套用到外殼。另外提供一個共用元件示範頁，涵蓋表格、表單、按鈕層級、停用說明、狀態色與識別碼複製。

## 驗收證據與限制

- **方向**：使用者在 `achromatic-ledger`、`framed-sheet`、`data-terminal` 三者中選定 `framed-sheet`（seed 1975997690）。
  - 產品識別：框架與主色取自棋盤深格的綠色，產品標記是兩格對角的棋盤。
  - 由本專案自行推導深色版 token，taste 抽出的方向只提供淺色版。
- **字型與圖示**：IBM Plex Sans／Mono 與 Material Symbols 改由 npm 套件提供，不再依賴 Google Fonts。
- **共用元件**：`app-action-button`、`app-status-pill`、`app-copy-id`、`app-product-mark`；示範頁在 `/design`，不列在側欄。
- **前端單元測試**：`npx ng test --watch=false` 共 4 例通過，涵蓋：
  - 側欄四區
  - 可按的動作
  - 有阻擋原因時停用、可聚焦，且無障礙名稱包含原因
  - 識別碼顯示前 8 碼，複製時寫入完整值
- **taste 量測**：`inspect.mjs --app` 在 1440、768、390 三種寬度下 0 FAIL。
  - 第一輪在 390 寬度出現一個 FAIL：側欄連結貼到右緣。已改成可換行的連結列，並加上 16px 邊距。
  - 剩下兩個 WARN，理由如下：
    - **字體數量**：被算進去的 Material Symbols 是圖示字型，不是文字字體。
    - **紙面空白**：依照框架紙面的規則，紙面本來就要撐滿視窗高度。
- **截圖檢查**：在 1280 淺色、900 深色、768、390 寬度下檢查，修正兩個問題：
  - 窄欄的中文逐字換行，改為除名稱欄外一律不換行。
  - 切換鈕原本是膠囊圓角，和其他控制項不一致，統一改成 6px。
- **限制**：
  - Design 外掛（design-system、design-critique）沒有載入這個工作階段的工具清單，所以規範整理和審查改依 taste 的工作畫面規則與七個檢查問題完成。如果之後重新啟動能載入，可以補跑一次 design-critique。
  - 示範頁表格中，第一筆的驗證 MAE 與識別碼取自實際教師標記；其餘兩筆的識別碼是示範值。
