## 要交付的行為

執行一行指令即啟動只接受本機連線的伺服器並開啟瀏覽器，看到含四區側欄與各區占位頁的 Angular 外殼；每區有網址，瀏覽器上一頁可返回。缺少前端建置時顯示建置指示。依賴改由 `requirements.txt` 安裝。

## 功能驗收與驗證方式

- [ ] 啟動指令開啟瀏覽器並顯示外殼。驗證：Agent 實際啟動並截圖。
- [ ] 伺服器拒絕非 127.0.0.1 連線。驗證：API 測試以非本機位址請求。
- [ ] 未建置前端時顯示建置指示而非空白頁。驗證：移除建置產物後啟動並截圖。
- [ ] 四區網址可直接開啟，上一頁返回前一區。驗證：端到端或實際瀏覽器操作。
- [ ] `requirements.txt` 在乾淨 `.venv` 可安裝現有依賴與 fastapi、uvicorn。驗證：新建臨時虛擬環境安裝並啟動。
- [ ] Node 套件與建置產物位於專案內且列入 `.gitignore`。驗證：`git status` 無建置產物。
