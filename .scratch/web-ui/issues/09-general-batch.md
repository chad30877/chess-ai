## 要交付的行為

在批次對戰設定雙方玩家、局數、同時對戰場數、開局步數與手數上限，開始、暫停、續跑、停止，看到已保存局數、工作狀態與結果，完成後可前往對局紀錄。

## 功能驗收與驗證方式

- [ ] 開始、暫停、續跑、停止行為與保存結果正確。驗證：沿用 self_play 測試情境的 API 測試。
- [ ] 停止局以使用者停止保存，不算和棋。驗證：API 測試。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
