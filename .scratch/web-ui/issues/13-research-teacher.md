# W13：教師先導、教師標記步驟與教師評分清單

狀態：ready-for-agent。
阻擋來源：W12、W04。
實作：Codex。
規格：[網頁介面](../spec.md)。
索引：[本批工作票](../README.md)。

## 要交付的行為

教師先導卡以選檔對話框選引擎、設定同時分析數、量測並選定預算、顯示預估耗時；教師標記卡開始、續跑、重新、停止並顯示有效／排除數；教師評分清單可搜尋、改名、前往；教師標記驗證結果依檔案變動快取。

## 功能驗收與驗證方式

- [ ] 先導與標記的開始、停止、續跑及保存正確。驗證：沿用既有教師測試替身的 API 測試。
- [ ] 教師標記未完成時學習步驟顯示缺少前置。驗證：API 測試。
- [ ] 標記驗證快取在檔案變動後失效。驗證：API 測試。
- [ ] 既有 5,809 筆標記進頁時間實測記錄。驗證：量測紀錄。
- [ ] 1280／900 截圖並經 design-critique。驗證：截圖與審查紀錄。
