# T03：單一權重候選從介面建立到成對比較

## 所屬規格

https://github.com/chad30877/chess-ai/issues/19

## 要交付的行為

使用者在 UI 選基準與一個已啟用位置權重，輸入數值清單，預覽候選後直接執行既有成對比較，從保存紀錄核對實際設定，不再手動複製 JSON。

## 驗收條件

- [ ] 從既有比較入口選基準與已啟用的 PST 或位置權重，列舉實際值即可預覽與執行；棋子價值、開關、階段模型固定，未選欄位繼承基準。
- [ ] 預覽顯示候選差異、有效候選數與對局數；拒絕非法值並明列去重與排除基準相同候選的結果，零個有效候選不得執行。
- [ ] 建立可保存的不可變實驗定義，包含完整設定、共同條件、版本、生成規則及穩定候選／棋局工作識別，為後續組合、結果與續跑提供同一份來源。
- [ ] 修改基準或條件使既有預覽失效；執行與保存的實際設定必須等於確認的預覽，不重新讀取已變更的來源設定。
- [ ] 各候選對基準沿用同局面交換黑白、相同搜尋條件及種子政策；完成一局就保存，既有比較紀錄仍可讀。
- [ ] 可經現有結果／回放入口檢視此次比較；停止與關閉沿用既有工作清理，不在此票宣稱已完成跨次續跑。
- [ ] 從 UI 事件經比較執行到真實保存／讀取的測試證明整條流程成立，基準設定不被覆寫。
