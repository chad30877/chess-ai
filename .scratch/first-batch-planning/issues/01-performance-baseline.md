# T01：全評分設定的可重跑效能剖析

## 所屬規格

https://github.com/chad30877/chess-ai/issues/18

## 要交付的行為

開發者能載入實際評分設定，在固定代表局面重跑深度 5 搜尋，取得完整條件、結果與成本剖析，回答全部評分項啟用時時間花在哪裡，而非只看到總秒數。

## 驗收條件

- [ ] 支援完整評分設定輸入，原預設操作仍可用；報告保存正規化後設定、程式版本、環境、一般／延伸深度、worker、表容量與其他搜尋開關。
- [ ] 固定並保存全項啟用及基準設定，涵蓋開局、中局、殘局與含歷史的局面；全項啟用可由報告核對。
- [ ] 報告包含局面與必要歷史、合法選步、分數、完成深度、逾時狀態、搜尋計數與耗時，能以保存條件重跑。
- [ ] 單 worker 剖析區分評分／分項建構、搜尋節點、棋盤歷史／置換鍵等成本；多程序條件另記冷啟動與重用差異。不以單 worker profiler 宣稱已剖析子程序全部成本。
- [ ] 量測重複執行，保存原始樣本與摘要；剖析和一般計時分開，逾時案例不冒充深度 5 完成。
- [ ] 以實測排序成本並說明限制；沒有證據的項目仍標待量測，提供 T02 可用的基準。
- [ ] 以工具實際執行驗收，不新增靜態欄位或 CI 耗時斷言測試；使用文件提供簡短重現方式。
