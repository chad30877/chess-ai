# T04：多參數組合與相對基準百分比

## 所屬規格

https://github.com/chad30877/chess-ai/issues/19

## 要交付的行為

使用者可選多個已啟用權重，以實際值或相對基準百分比、數值清單或起訖間隔生成組合，預覽後直接比較全部有效候選。

## 驗收條件

- [ ] 支援數值清單及起點／終點／正間隔，範圍只產生不超過終點的間隔值；拒絕非法、非有限及倒置範圍。
- [ ] 100% 還原基準、150% 為基準 1.5 倍；顯示實際值，不將各項正規化為合計 100%。零基準使用實際值，模式切換不改變有效候選。
- [ ] 已啟用階段混合時可分別選中局／殘局欄位；未啟用時不產生無作用的殘局調整，不隱含啟用評分項。
- [ ] 兩個參數各三個非基準值生成九組候選，可全部預覽、執行並核對保存結果，不受舊七份限制。
- [ ] 以完整有效設定去重，百分比與實際值產生相同設定時不重複對戰；穩定候選識別不依顯示名稱或排序位置。
- [ ] 預覽顯示計畫對局數與去重結果；大量組合先計數，UI 不因同步展開而失去回應，無靜默截斷。使用者開始後才派工。
- [ ] 與 T03 相同的實驗定義保存所有有效候選及生成規則，回放中的實際設定與預覽一致；測試涵蓋九組、零基準、重複與範圍邊界。
