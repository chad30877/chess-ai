## 已確認測試入口

- 效能：以搜尋公開入口驗證分數、合法選步、棋盤歷史、取消與程序清理；完整量測走獨立效能工具，不用 CI 秒數門檻。
- UI：以應用程式事件／比較執行入口串到實際保存與重新讀取，驗證預覽等於實際設定、配對統計與續跑。候選數值規則用少量行為測試補足。
- 六張票的粒度與依賴已核准；目前可開始的工作為 #20 與 #22，效能優先。
