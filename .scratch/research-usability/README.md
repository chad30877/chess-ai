## 提議的測試入口

主要使用現有應用程式 UI 事件入口，實際走選取、執行、保存、重開與套用設定。只有外部 UCI 教師、作業系統選檔結果與時間／故障邊界採可控制替身；必要時由現有公開教師執行及載入入口驗證並行、凍結與續跑。真實 Stockfish 短流程及必要畫面檢查由 Agent 執行，不要求使用者逐票操作。不測靜態文字，也不要求 README 新環境驗收。
