# R05：以名稱與群組篩選評分設定檔並選取比較候選

狀態：本機草稿，待切票核准後標為 `ready-for-agent`；不發布 GitHub。

## 父規格

本批本機規格「研究前的環境準備、教師並行與操作改善」。

## 建置內容

所有評分設定入口改用共用的獨立選擇小視窗，提供名稱搜尋、五群組勾選、可捲動清單與實際群組摘要。預設找出包含所選群組的設定，切換「僅此組合」後排除其他群組；比較候選能一次多選。即使兩組組合及其版本增加，也不必建立更多固定分類。

## 必要驗收

- [ ] 真人、一般批次白黑雙方、比較基準／候選及回放編輯器皆能開啟共用選擇流程並實際套用設定；以各入口 UI 事件驗證。
- [ ] 名稱搜尋與捲動能找到超過一頁的設定；以大量不同名稱及中文名稱資料驗證。
- [ ] 同時勾選活動力與王安全時，結果包含所有同時啟用兩組的設定，亦可含其他群組；以不同組合資料驗證。
- [ ] 開啟「僅此組合」後排除含額外群組的設定；以相同資料與切換事件驗證。
- [ ] 群組判定依實際啟用項，部分啟用仍屬該群組，不受檔名或分階段開關誤導；以對應設定實際篩選驗證。
- [ ] 未篩選可查看全部且純子力可被找到及套用；以事件流程驗證。
- [ ] 比較候選能一次多選，確認後的實際比較參與者不重複且排除基準；以比較建立入口驗證。
- [ ] 取消單選或多選視窗均不改變先前選擇；以取消前後設定比對驗證。
- [ ] 另存新設定後重新開啟選擇器即可查到；以另存及重新選取流程驗證。
- [ ] 無法讀取的設定檔不使整個選擇流程失效，也不能被當成有效設定套用；以損壞及遺失檔案案例驗證。
- [ ] Agent 畫面檢查確認長名稱、群組摘要及大量結果可操作，不依賴預建組合分類；保存操作證據。

## 阻擋來源

無，可立即開始。

## 文件與結案

- [ ] 同步選擇操作說明及測試導覽、記錄驗收證據，同步本機驗收狀態並建立提交。

## 人工重現方式（非額外驗收）

開啟設定選擇器，搜尋名稱並勾選活動力與王安全；切換「僅此組合」，比較結果差異，再到評分比較一次選取多個候選。
