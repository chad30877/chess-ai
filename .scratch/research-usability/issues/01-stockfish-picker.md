# R01：從教師先導選取 Stockfish 執行檔

狀態：本機草稿，待切票核准後標為 `ready-for-agent`；不發布 GitHub。

## 父規格

本批本機規格「研究前的環境準備、教師並行與操作改善」。

## 建置內容

使用者開啟新先導時看到專案內 Stockfish 範例位置，也能按鈕開啟檔案選擇器，選定執行檔後完成既有先導。重開既有先導沿用保存路徑，選檔不覆寫既有實驗條件。

## 必要驗收

- [ ] 新先導以所在專案解析範例路徑，不綁定原電腦位置；以兩個暫存專案根目錄的 UI 行為驗證。
- [ ] 檔案選擇器回傳的有效路徑會成為新先導實際使用的教師；以 UI 事件走到教師身分保存驗證。
- [ ] 含空白或中文字的執行檔路徑能完成選取及啟動；以外部程序整合案例驗證。
- [ ] 取消選檔保留原值；以 UI 事件驗證。
- [ ] 不存在或無法使用的執行檔會顯示可辨識錯誤，修正後可建立新先導；以錯誤與恢復流程驗證。
- [ ] 重開既有先導顯示其保存路徑，不以新預設值改寫；以重開與快照比對驗證。
- [ ] Agent 以真實系統檔案選擇器選取本機 Stockfish 並完成短先導，保存操作證據。

## 阻擋來源

無，可立即開始。

## 文件與結案

- [ ] 同步相關操作說明及測試導覽、記錄驗收證據，同步本機驗收狀態並建立提交。

## 人工重現方式（非額外驗收）

進入新先導，檢視預填路徑、取消一次選檔，再選取其他位置的 Stockfish 執行短先導；重開確認使用的是保存路徑。
