# R04：真人與回放標示最後一手所有變動格

狀態：草稿，待切票核准後發布。

## 父規格

研究前的環境準備、教師並行與操作改善；發布時填入父規格編號。

## 建置內容

真人與回放棋盤以透明綠標示造成目前局面的最後一手所有變動格。沿用共用棋盤及完整走棋歷史，跳步、倒退、翻轉、縮放後仍呈現正確位置。

## 必要驗收

- [ ] 真人及回放一般走棋標示起點與終點兩格；以實際走棋及回放事件驗證。
- [ ] 王車易位標示四個變動格；以合法易位歷史及畫面檢查驗證。
- [ ] 吃過路兵標示三個變動格；以合法歷史及畫面檢查驗證。
- [ ] 回放跳步或倒退後標示造成目前局面的最後一手；以事件流程與當前歷史比對驗證。
- [ ] 起始或無歷史局面不猜測最後一手；以兩類局面驗證。
- [ ] 翻轉及縮放後色塊仍位於正確棋格；以既有棋盤座標與 UI 操作驗證。
- [ ] 透明綠色塊與選取框、合法目的格提示及棋子可同時辨識；以 Agent 畫面檢查保存證據。

## 阻擋來源

無，可立即開始。

## 文件與結案

- [ ] 同步相關操作說明及測試導覽、記錄驗收證據，依專案流程提交並結案。

## 人工重現方式（非額外驗收）

真人走一步後查看色塊；回放包含易位與吃過路兵的棋局，前進、倒退、翻轉並調整視窗大小。
