# R07：整理 Windows CMD 環境準備與資源下載範例

狀態：本機草稿，待切票核准後標為 `ready-for-agent`；不發布 GitHub。

## 父規格

本批本機規格「研究前的環境準備、教師並行與操作改善」。

## 建置內容

README 成為精簡的環境準備與操作入口：假設已安裝 Git，提供 CMD 的專案取得、Git 設定、Python 環境、依賴及啟動指令。以目前 Stockfish、棋譜與開局庫示範下載，明確標示可換其他相容來源，並連到既有詳細操作文件。

本票以文件檢閱交付，不要求全新電腦驗收或新增靜態文字測試。教師選檔、workers 與先導估時說明以已完成介面為準；不等待不影響環境準備的棋盤、設定選擇與真人狀態功能。

- [ ] Git 已安裝的前提、CMD 專案取得及 Git 設定指令完整，提交身分設定置於開發用途；以文件檢閱驗證，不加入 Git 安裝教學。
- [ ] Python 環境、必要依賴與啟動指令不綁定作者電腦配置；以逐段 CMD 語法與相對位置檢閱驗證。
- [ ] Stockfish 下載與解壓範例對應可用執行檔及教師選檔流程；以官方來源核對及介面對照驗證。
- [ ] 棋譜下載範例標明來源與目前支援的輸入格式；以來源核對及既有資料入口對照驗證。
- [ ] 開局庫說明已隨專案提供，另附同版本取得／修復範例並標明 TSV 格式；以來源及專案內容檢閱驗證。
- [ ] 各資源明示只是範例，可換其他相容來源，不誤稱任意格式皆可使用；以文件檢閱驗證。
- [ ] 教師選檔、workers 及先導預估的簡短說明對應已交付操作；以實際介面對照驗證。
- [ ] 重複歷史整理為目前狀態及既有文件連結，保留必要操作入口；以文件結構與連結檢閱驗證。
