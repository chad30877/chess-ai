# R06：真人顯示開局庫與實際搜尋狀態

狀態：本機草稿，待切票核准後標為 `ready-for-agent`；不發布 GitHub。

## 父規格

本批本機規格「研究前的環境準備、教師並行與操作改善」。

## 建置內容

真人對戰能看出仍在開局庫，只有實際搜尋時才顯示 AI 思考中。維持離庫政策與其他回合狀態；一般批次不新增狀態，只把既有開局步數表達為雙方合計落子次數。

## 必要驗收

- [ ] 使用開局庫的真人對戰於庫內顯示庫內狀態；以實際開局選步事件及畫面驗證。
- [ ] 首次離庫後進入實際搜尋才顯示 AI 思考中；以受控背景搜尋與 UI 事件驗證。
- [ ] 真人回合、等待間隔、暫停、終局及錯誤不被誤標為 AI 思考中；以狀態切換案例驗證。
- [ ] 首次離庫後即使回到庫內局面也不重新用庫；沿用既有開局政策回歸驗證。
- [ ] 未使用開局庫的策略不宣稱正在以庫選步；以不同玩家策略的真人流程驗證。
- [ ] 一般批次開局步數維持任一方落子一次計一步，輸入 2 對應最多兩次落子；以實際批次建立及保存開局記錄驗證。
- [ ] 比較模式的固定共同開局線條件不受此次修改影響；以既有比較流程回歸驗證。

## 阻擋來源

無，可立即開始。

## 文件與結案

- [ ] 同步狀態與開局步數說明及測試導覽、記錄驗收證據，同步本機驗收狀態並建立提交。

## 人工重現方式（非額外驗收）

真人對戰設定短開局上限，觀察庫內、輪到自己與離庫搜尋；再暫停及結束，確認提示對應當下狀態。
