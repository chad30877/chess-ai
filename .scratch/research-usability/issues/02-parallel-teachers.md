# R02：可調 workers 的教師先導與標記停止續跑

狀態：草稿，待切票核准後發布。

## 父規格

研究前的環境準備、教師並行與操作改善；發布時填入父規格編號。

## 建置內容

使用者設定同時分析局面數，以多個單執行緒 Stockfish 完成先導及同條件教師標記。每局面正確保存，停止、失敗與重開可保留成果，舊單程序實驗仍能使用。此票包含 UI、凍結條件、實際程序、保存與驗證，不拆成只能交付內部框架的水平票。

先導需保存兩種預算各自在所選 workers 下的整批經過時間與完成數，供下一票估時；同一預算的量測不得受另一預算同時爭用這批 workers 而失去獨立推估依據。此票不新增預估畫面。

## 必要驗收

- [ ] 新先導提供 workers 正整數設定，預設為可用 CPU 與 4 的較小值且至少 1；以 UI 操作及少核環境輸入驗證。
- [ ] 多個局面確實同時由不同 Stockfish 處理且不超過設定並行數；以可控制外部教師的工作重疊及完成記錄驗證。
- [ ] 每個教師均以單執行緒及相同凍結條件分析；以外部教師接收的條件與保存身分驗證。
- [ ] 亂序完成仍將正確歷史及教師結果提交到對應局面；以不同局面可辨識結果及載入後比對驗證。
- [ ] workers 隨先導、預算選擇及標記條件凍結，後續標記不能偷偷換數量；以 UI 建立、重開及條件相容性測試驗證。
- [ ] 缺少 workers 的既有資料按原單程序條件載入及續跑，不改寫已保存身分；以舊版資料回歸驗證。
- [ ] 先導兩種預算各自保存可供重開的實測整批經過時間與完成數；以可控制時間及重疊工作驗證，不將各程序時間相加當整批時間。
- [ ] 先導停止保留已提交量測，未完成量測不能選定預算；以 UI 停止與重開驗證。
- [ ] 教師標記停止或關閉後保留已提交局面並釋放背景程序；以實際程序及 UI 事件驗證。
- [ ] 重開續跑只補未提交或失敗局面，不覆寫已完成記錄；以記錄內容與外部工作觀察驗證。
- [ ] 任一教師失敗會保留可重試的局面資訊，不把整批誤報完成；以程序失敗及重試整合案例驗證。
- [ ] 多 workers 共用整次八小時上限且不自動續跑；以可控制時鐘驗證到期停止與程序清理。
- [ ] 實驗互斥執行與完整標記後才能學習的規則仍有效；以既有公開流程回歸驗證。
- [ ] Agent 完成真實 Stockfish 多程序短流程，包含標記停止及重開續跑，記錄條件、耗時與保存結果；不要求固定加速倍率。

## 阻擋來源

無，可立即開始；可沿用原有手動路徑，不依賴 R01。

## 文件與結案

- [ ] 同步並行條件與測試導覽、記錄驗收證據，依專案流程提交並結案。

## 人工重現方式（非額外驗收）

建立少量資料，以 2 workers 完成先導並選預算，開始標記後停止；重開續跑，檢查設定、完成數及已保存局面。
