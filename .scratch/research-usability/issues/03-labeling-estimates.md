# R03：由先導預估兩種節點預算的後續標記耗時

狀態：本機草稿，待切票核准後標為 `ready-for-agent`；不發布 GitHub。

## 父規格

本批本機規格「研究前的環境準備、教師並行與操作改善」。

## 建置內容

完成先導後，使用者在選擇預算前即可比較 50,000 與 200,000 節點各自的後續標記預估時間。預估採同 workers 的實際量測與尚需分析的局面數，並能保存重開；只涵蓋教師標記，不擴充為訓練或對戰估時。

## 必要驗收

- [ ] UI 在選定預算前並列兩種預算各自的後續標記預估；以完成先導後的實際事件流程驗證。
- [ ] 預估使用各預算實測整批經過時間及完成數，不將單 worker 時間除以 workers；以可手算的並行量測資料驗證。
- [ ] 待標記數扣除同條件可重用的先導記錄；以可重用與不可重用記錄混合的案例驗證。
- [ ] 仍需教師分析才會被篩除的局面保留於待標記工作量；以篩除條件案例驗證。
- [ ] 少於 100 個先導局面時使用實際完成數；以不足量資料整合案例驗證。
- [ ] 無完成量、無可用時間或舊先導缺必要量測時顯示無法估計，不輸出虛假時間；以缺資料案例驗證。
- [ ] 重開先導可取得相同條件與量測的預估，不重跑教師；以保存、重開及結果比對驗證。
- [ ] UI 清楚區分實測耗時、預估耗時及其節點條件，選擇後仍凍結正確預算；以事件流程與必要畫面檢查驗證。

## 阻擋來源

- R02：需要同 workers 的分預算實測經過時間、完成數及保存條件。

## 文件與結案

- [ ] 同步估時說明及測試導覽、記錄驗收證據，同步本機驗收狀態並建立提交。

## 人工重現方式（非額外驗收）

完成先導後比較兩種預算的實測與預估，選定其中一個，重開確認條件與預估仍可追溯。
