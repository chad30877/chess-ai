# 設計系統

網頁介面的外觀與元件規則，對所有頁面一體適用。token 定義在 `web/src/styles.scss`，畫面只使用 token，不直接寫色碼。實際樣子可以開啟 `/design` 元件示範頁查看。

## 方向

採用 design-taste-frontend 的工作畫面方向「框架紙面」（`framed-sheet`，seed 1975997690）：

- 側欄放在淡色的框架上，工作內容放在白色紙面上。紙面距離視窗右側與下緣 8px，有 1px 邊線、16px 圓角，不加陰影。
- 深度只靠一階明度差表現，每層之間不另外畫線。

產品識別取自棋盤本身：

- 框架是棋盤深格的低彩度綠灰
- 主色是深格綠
- 產品標記是兩格對角的棋盤

彩色像素控制在畫面的 3% 以內，顏色只用在資料、狀態與唯一的主要動作上。

## 色彩

深淺色跟隨系統，每個 token 都用 `light-dark()` 同時定義兩種值。

| token | 用途 |
| --- | --- |
| `--ground` | 框架與側欄 |
| `--surface` | 紙面、表格、表單 |
| `--raised` | 列懸停、次一階表面 |
| `--active` | 側欄目前項目、選取 |
| `--border`、`--rule` | 紙面邊線、表格列分隔 |
| `--control` | 輸入框外框 |
| `--text`、`--muted` | 正文、次要文字 |
| `--accent`、`--on-accent` | 主要按鈕、焦點、目前選取的資料 |
| `--positive`、`--negative`、`--warning` 及 `--pill-*` | 狀態 |
| `--board-light`、`--board-dark` | 棋盤格與產品標記 |

不使用漸層、光暈、毛玻璃、紫色或靛藍色，也不用奶油底配赭紅的配色。

## 字體

- 正文用 IBM Plex Sans，中文字元退回微軟正黑體 UI。字重只用 400、500、600。
- IBM Plex Mono 只用在識別碼、群組組成代號這類鍵值。
- 字級只有五種：標題 22、區段 16、主要數字 28、正文 14、小字 12。
- 所有數字使用 `tabular-nums`，表格中的數字靠右對齊。
- 一律用一般大小寫，不用全大寫加字距的小標籤。
- 字型與圖示（Material Symbols Outlined）都由 npm 套件提供，離線也能正常顯示。

## 間距與尺寸

- 間距一律 24px，水平、垂直相同；紙面內距也是 24px。
- 側欄寬 228px，控制項高 32px，表格列高 48px。
- 圓角只有三種：控制項 6px、卡片 8px、紙面 16px。
- 密度採緊湊（Material density -2）。

## 元件規則

1. **元件依用途區分**：輸入用輸入框，選項用下拉選單或切換鈕，清單用表格。只有「動作」才做成按鈕。
2. **主要按鈕最多一個**：每個區塊最多一個主要按鈕（實心主色），其他都用次要按鈕（外框）。區塊標題列右側放主要動作。
3. **不能用的動作要說明原因**：使用 `app-action-button` 並傳入 `blockedReason`。停用時，滑過或聚焦都會顯示原因，螢幕閱讀器也會讀出。不要單純把按鈕反灰。
4. **狀態要有顏色、圖示和文字**：使用 `app-status-pill`，分成 positive、negative、warning、neutral 四種，不能只靠顏色區分。錯誤和警告不要混在統計數字裡。
5. **名稱優先**：使用 `app-copy-id` 顯示識別碼，只露出前 8 碼，可以一鍵複製完整值，放在名稱下方或詳細資訊裡。
6. **表格**：
   - 標題列用 12px 灰字，不加底色。
   - 列與列之間用 1px 的 `--rule` 分隔，不做斑馬紋。
   - 名稱欄寬度最大，文字靠左，數字靠右。
   - 缺值顯示灰色破折號「—」，零就照實顯示 0。
7. **導覽**：側欄的目前項目以 `--active` 灰底標示，不加彩色條；每一頁都有自己的網址。
8. **不使用的裝飾**：陰影只留給浮在畫面上的元素（選單、對話框），其餘一律不用。也不要用帶色方塊的圖示卡、序號 01／02，或是放在標題上方的小標籤。

## 手機寬度

寬度在 720px 以下時，框架收起，紙面就是整個畫面，側欄改成頂端可換行的連結列。表格每一列變成兩行：第一行是名稱，第二行放其餘欄位。主要使用情境是桌面，手機只要求不破版。

## 檢查方式

每張畫面工作票的檢查方式：

1. 用 `node <skill>/scripts/inspect.mjs --app <網址>` 量測，必須 0 FAIL。WARN 要能說明理由。
2. 截圖 1280 與 900 兩種寬度，深淺色各一。
3. 依 taste 工作畫面的七個問題逐項檢查並記錄。

目前固定會出現兩個 WARN，理由如下：

- **字體數量**：被算進去的 Material Symbols 是圖示字型，不是文字字體。
- **紙面空白**：依照這個方向的規則，紙面本來就要撐滿視窗高度。
