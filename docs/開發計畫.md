# 開發計畫

更新日期：2026-10-14。本文件記錄目前功能狀態與已確認的後續方向；詳細設計與實驗資料見各功能文件，程式變更歷史由 Git 保存。

## 目前狀態

| 範圍 | 目前狀態 |
| --- | --- |
| 局面評分 | 回放可查看選定局面的靜態總分與評分項分解 |
| 評分設定檔 | 版本化 JSON 設定；可從回放設定建立草稿、即時重算並另存新檔 |
| 真人對 AI | 支援 Random、Greedy 與固定深度 Alpha-Beta，可選已保存的評分設定檔 |
| 評分比較 | 一份基準可與多份候選在共同條件下分別配對比較，結果並列呈現且不自動排名 |

## 後續方向

目前沒有已排定的功能工作。評分項集合維持現況；新增評分項或自動調參需另行規格化。

## 調整與驗證方式

每輪只調整少量相關權重並記下預期影響。回放分數用來理解設定對特定局面的作用；棋力效果透過固定搜尋條件、相同起始局面及交換黑白的對局比較判斷。候選設定再以未用於調整的局面驗證，避免只適配已反覆查看的棋局。詳細實驗方法見[評分調整與實驗](評分調整與實驗.md)。
