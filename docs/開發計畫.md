## 目前進度摘要

| 範圍 | 目前狀態 | 下一步 |
| --- | --- | --- |
| UI | 批次設定統一一般對戰／評分比較；共用背景控制與進度，棋力比較檢視既有結果、設定差異與回放 | 以比較入口驗證評分效果 |
| 比較流程 | API／CLI／UI 已共用固定深度 Alpha-Beta 評分比較、交換黑白、逐局保存與合作式停止；固定時間尚未接入 | 初輪固定深度驗證後補固定時間比較 |
| 棋力效果 | 分階段評分、兵形、活動力、國王安全與棋子協調已實作，效果待驗證，目前預設關閉 | 逐組比較候選與穩定設定，記錄結果與採用決定 |

## 接下來的順序

1. 棋力驗證：先驗證分階段評分，再逐組驗證其他評分項。
2. 棋力驗證：接入固定時間比較，確認相同時間下的實際效果。
3. 按需求擴充搜尋設定比較與統計分析，結果仍由同一 UI 顯示。

UI 是主要操作入口；棋規、配對、統計與保存由共用後端負責，CLI 保留作除錯與重現入口。既有 CLI 可先進行實驗，不必等待 UI 全部完成。

- **狀態：** 後續候選，尚未整合，不阻擋評分效果驗證；原有 CLI 資料生成的多程序功能保留。
- **目的與範圍：** 兩種批次模式共用多場對戰並行，每場搜尋維持單執行緒；沿用模式設定、配對種子與保存格式。
- **相依條件與驗收：** 以目前共用執行控制與逐局保存為基礎；並行時正確停止、保留已保存前綴，不重複對局或編號，不遺失錯誤；比較維持相同開局、交換黑白與完整配對統計，記錄實際 workers 及硬體條件。不得將一般批次追認為公平比較。

## 棋力驗證

### 評分效果

- **狀態：** 待驗證，主要操作使用批次設定的評分比較模式。
- **方法：** 固定程式版本、搜尋設定與深度，以多個預先選定的開局各打兩局、交換黑白；一次只改一組評分項或少量相關權重，先從分階段評分開始。Random 用於基本流程檢查，棋力對照使用穩定設定；調整與最終驗證使用不同開局集。確定性 Alpha-Beta 重複相同局面不視為新增獨立證據。
- **完成條件：** 保存實際設定、開局、種子、結果與耗時；超過步數上限、停止及失敗不算和棋。預先決定對局數與判斷方式，報告完整及不完整配對、樣本範圍與結論限制，明確記錄採用、維持關閉或繼續驗證；功能測試或小樣本得分率超過 50% 不代表已證明提升棋力。

### 固定時間比較

- **狀態：** 待整合，安排在初輪固定深度驗證後。
- **範圍：** 共用比較 API／CLI／UI 接入每步時間限制與深度上限，雙方使用一致預算；保存實際限制、最後完整搜尋深度、停止原因及耗時，報告硬體與並行條件，保留固定深度及舊資料讀取。
- **完成條件：** 正確區分固定深度與固定時間；逾時／取消回傳合法備援，未完成的深度不冒稱完成，根棋盤與對局歷史不受污染。以可控時鐘測試時間與停止語意，實際耗時不要求跨機器一致。

### 搜尋設定比較與統計分析

- **狀態：** 按需求分開立項。
- **搜尋比較：** 現有流程僅允許相同搜尋設定的評分比較；後續另定比較類型，允許指定搜尋開關差異，固定其他評分、開局與預算，保存雙方實際設定。搜尋成本改善與棋力結果分開判斷。
- **統計分析：** 以交換黑白的完整配對處理不確定性，不完整配對另列；加入信賴區間／相對 Elo 時記錄方法、預算與樣本條件，樣本不足明確提示。用已知結果與邊界案例測試，不只驗證圖表顯示。

比較方法見 [評分調整與實驗](評分調整與實驗.md)，特徵定義見 [搜尋與評分](搜尋與評分.md)。
