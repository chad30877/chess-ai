## 已確定的決策

- 保留既有 UI 自動對戰、真人操作、日期回放、批次資料及共用棋規；保留 `assets/pieces` 與 SVG 失敗時的 PNG 備援。
- 舊 ML 已移除，不恢復舊模型或相容別名。Random 作基本基準，穩定版本／設定用於退步比較。
- 評分拆成特徵、權重與分項輸出，固定白方視角與 pawn 分數單位。預設維持 material + PST；新特徵須定義單位、方向、適用階段及重複計分風險。
- 對戰保存實際玩家使用的完整評分／搜尋設定與版本，名稱不能代替數值；格式擴充須明確處理舊資料相容。
- 一次只比較一組特徵或少量相關權重，固定其他條件。實作正確、搜尋成本與棋力效果分別判斷；先做手動小實驗，再評估自動調參。
- 開局庫屬選步來源，採先查庫、未命中再搜尋的獨立流程，不列入靜態評分項。

## 任務粒度與交付規則

- 每階段只有一個主要目標，包含必要的介面、設定、測試、文件與 commit，須可獨立驗證及回滾；不混合分類搬檔、新特徵、搜尋優化與調參。
- 依 [AGENTS.md](../AGENTS.md)，每次改動編寫或更新相關測試，交付前全部測試與驗證通過，再建立對應 Git commit。保留有效驗證；純分類需確認原有案例仍被發現並執行，棋規、對局與儲存語意不變。
- 階段完成後更新本文件的狀態、日期及功能文件連結；規格與限制寫在功能文件，逐次測試數量、單次效能紀錄與詳細完成報告不累積在本計畫。

### 優先：驗證 E1–E5 的棋力效果

- **目的／狀態：** 棋力效果待驗證。判斷候選特徵及權重是否值得採用，先從 E1 開始，再逐組評估；不因功能完成直接開啟預設。
- **相依：** P4、各評分項與 P5 Alpha-Beta 固定深度比較均已具備。固定時間整合不是啟動本輪的前置條件。
- **範圍：** 固定程式版本、搜尋深度／選項、其他特徵與權重；預先選定起始局面及種子，交換黑白比較穩定設定與單組候選。先檢查流程，再跑完整對局，使用未參與調整的局面作獨立驗證。Random 僅作基本檢查，主要對照穩定版本。方法見 [手動比較流程](評分調整與實驗.md#手動比較流程)。
- **驗收：** 設定、預算、種子與對局可追溯；勝和敗與未完成分開，截斷／停止／失敗不算和棋；報告樣本範圍、耗時及結論限制，明確決定採用、保留關閉或繼續驗證。小樣本不足時維持「待驗證」，不以勝過 Random 或功能測試宣稱提升棋力。

### 後續整合：P5 固定時間比較

- **目的／狀態：** 尚未整合。讓相同時間預算下的評分成本與搜尋效果可以公平比較。
- **相依：** S3 核心時間／取消與現有固定深度比較已完成；先定義獨立的時間預算模式、每步限制及深度上限語意。
- **範圍：** 接入比較 API／CLI，雙方使用一致時間限制與搜尋選項，保存實際設定、最後完整深度、停止原因與耗時；一般深度、最深探索及 quiescence 延伸須分清。保留固定深度模式及舊資料讀取。
- **驗收：** 不混用或誤標兩種預算；假時鐘／取消測試涵蓋逾時與未完成首輪，回傳合法備援且不冒稱完成指定深度；根棋盤不變、設定快照一致、配對及結果統計正確。合作式停止不能強制中斷 evaluator，實際耗時與結果不要求跨機器完全相同。

### 按需求安排：一般對戰與 UI 的 Alpha-Beta 整合

- **目的／狀態：** 尚未整合。比較入口以外，目前一般生成／UI 使用 Random、Greedy，真人模式另有 Human；`engine_match` 僅有 random／material。
- **相依：** 搜尋核心與實際設定保存已具備；依使用需求選定一個入口及預算模式，再立獨立任務。
- **範圍：** 每次只接一個入口，包含玩家選擇、限制傳遞、共用和棋政策與真實設定保存；UI 階段另處理背景執行及暫停／停止，不一起重做既有流程。
- **驗收：** 新選項確實使用 Alpha-Beta 並產生合法走法；搜尋限制與保存值一致，舊選項、對局保存及回放仍可用。UI 整合須驗證搜尋期間介面可回應與停止行為；此項不阻擋現有 P5 棋力實驗。

## P7 評估自動調參

- **目的／狀態：** 遠期待評估，尚未實作；評估能否比手動調整更有效，不恢復舊 ML 路線。
- **相依：** P5 與至少一輪穩定、可重現的 P6 手動實驗；先確認比較方法能辨識退步與收益。
- **範圍：** 先定目標、少量參數、計算預算與資料分組，再選網格／逐項搜尋、對戰調參或教師評分等方法；不預先建立空框架。
- **驗收：** 調整與驗證資料分離，若使用對局資料則按整盤分組；以獨立驗證及穩定版本對照評估收益，未完成對局不硬給和棋標籤。不只追求對 Random 的勝率，也不把原 evaluator 分數當標籤後宣稱學得更強棋力。證據不足時可決定不立項。
