# 開發計畫

更新日期：2026-10-14。本文件只記錄目前狀態與已確認的後續方向；細節留在功能文件，變更歷史由 Git 保存。

## 目前狀態

| 範圍 | 目前狀態 | 後續方向 |
| --- | --- | --- |
| 局面評分 | 引擎已有總分與各評分項分解；回放畫面尚未顯示 | 在回放資訊面板顯示選定局面的靜態評分 |
| 評分設定檔 | 有版本化 JSON 檔及多候選比較；沒有編輯器 | 從回放設定建立副本、即時重算並另存新檔 |
| 真人對 AI | 支援 Random／Greedy；尚未選擇評分設定檔或使用 Alpha-Beta | 加入固定深度 Alpha-Beta，初始深度 2，選用已保存設定檔 |

評分項集合先維持現況，不把新增評分項列入這輪方向。

## 後續順序

1. **回放分數拆解**：在回放資訊面板顯示白方視角、以兵為單位的局面靜態總分；以 0 為中心的雙向條形圖呈現已啟用評分項的精確貢獻，右側有利白方、左側有利黑方。選取棋譜步數時分析落子後的局面。
2. **回放調整設定**：以該棋譜實際使用的設定作為副本起點；依類別收合現有可調項，預設展開已啟用項。調整時即時重算目前局面的靜態評分，另存新設定檔，不覆寫既有檔案。
3. **真人對 Alpha-Beta**：真人對局設定頁選擇已保存的評分設定檔，初始預選 `stable.json`；Alpha-Beta 固定深度，預設 2，只提供深度選項，其他搜尋選項沿用現有預設。棋譜保存實際使用的評分及搜尋設定。

## 調整與驗證方式

每輪只調整少量相關權重並記下預期影響。回放分數用來理解設定對特定局面的作用；棋力效果透過固定搜尋條件、相同起始局面及交換黑白的對局比較判斷。候選設定再以未用於調整的局面驗證，避免只適配已反覆查看的棋局。詳細實驗方法見[評分調整與實驗](評分調整與實驗.md)。
